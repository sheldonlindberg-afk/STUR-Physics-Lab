# Internal Documentation

**This folder contains internal documentation that is NOT intended for display on the STUR Physics Lab website.**

These documents are for repository maintainers and contributors only. They are not linked from any public-facing HTML pages.

## Contents

- `PEER_REVIEW_REPORT.md` — Comprehensive peer review of the STUR Physics Lab documentation
- `PEER_REVIEW_THEORY_CLOSURE.md` — Focused review of theory closure and reasoning

## Why Internal?

Peer review documents contain:
- Working notes and recommendations for maintainers
- Issue tracking for documentation improvements
- Internal assessments that may be misinterpreted out of context

The public-facing website presents the finalized theory documentation. These internal documents track the review and improvement process.

## Access

These files are accessible to anyone who browses the GitHub repository directly, but they are intentionally not linked from the website UI to keep the user experience focused on the theory content.
