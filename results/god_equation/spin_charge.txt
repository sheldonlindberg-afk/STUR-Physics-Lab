   field-angular-momentum shift J = x Phi / 4 pi = 3x/2  (mod 1) for anything bound to the fold:
     quark         B-L = 1/3   J mod 1 = 1/2   -> half-integer (fermion)

     m = 1, k = 2:  quark J = 1/2, lepton J = 1/2   statistics OK

   This object is KNOWN: the minimal grand-unified monopole carries colour-magnetic flux that
   compensates fractional charges (LIT, recalled: SU(5) Dokos-Tomaras 1980; SO(10) analogous).

==============================================================================

   What forces 1/3 is the number of colours, via [SU(2)]^2 U(1)_Y: N_c Y_Q + Y_L = 0:
     N_c = 1:  Y_Q = 1/2    -> Q_u = 1      Q_d = 0

   -> the thirds come from N_c = 3, not from the twist. The twist only RESPECTS them.
