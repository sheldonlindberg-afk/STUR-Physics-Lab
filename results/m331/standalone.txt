S2  SU(3)_L anomaly + asymptotic freedom of colour  =>  N_c odd, N_g = N_c
==============================================================================
   SU(3)_L anomaly: #triplets = #anti-triplets  ->  N_g (1 + N_c) = 2 n N_c
   Asymptotic freedom with 3 N_g quark flavours: 11 N_c - 6 N_g > 0
   All solutions for 2 <= N_c <= 60: 29; first: (N_c=3, N_g=3, n=2), (N_c=5, N_g=5, n=3), (N_c=7, N_g=7, n=4), (N_c=9, N_g=9, n=5), ...
   Proof: if N_c is odd, gcd(N_c + 1, 2 N_c) = 2, so N_c | N_g, and N_g < 11 N_c/6 leaves
   N_g = N_c. If N_c is even, gcd = 1, so 2 N_c | N_g, which violates asymptotic freedom.
   SU(2) doublets then number 2 n N_c, always even: Witten's anomaly is automatic.
   [PASS] every solution has N_c odd and N_g = N_c (29 solutions)
   [PASS] gcd(N_c + 1, 2 N_c) = 2 for odd, 1 for even N_c
