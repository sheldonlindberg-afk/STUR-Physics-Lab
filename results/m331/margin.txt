==============================================================================
M2  Which masses matter: d ln(pole)/d ln(mass) at the floors, M_V = 3.755 TeV
==============================================================================
   M_V (vectors)         : -0.160
   m_J (exotic quarks)   : +0.297
   m_E (heavy leptons)   : +0.284
   m_S (heavy scalars)   : +0.024
   second doublet heavy instead of light: ln(pole) shifts by +0.001
   Heavier exotic fermions raise the pole; the scalars barely matter. A heavier M_V at
   fixed fermion masses lowers it: the light fermions then run longer below M_V.

M3  Worst case over the allowed spectrum (beta = +1/sqrt3, N_c = 3, alpha = 1)
==============================================================================
   floors: M_V >= 3.755 TeV (Z' >= 4.6 TeV), m_J >= 1.3 TeV, m_E >= 0.1 TeV, m_S >= 0.1 TeV; M_V up to 30 TeV
   three loops, Yukawas    : 0.445 M_Pl   (at M_V = 30.0 TeV, floor multiples m_J, m_E, m_S = 1, 1, 1, n_light = 2)
   three loops, no Yukawas : 0.429 M_Pl   (at M_V = 30.0 TeV, floor multiples m_J, m_E, m_S = 1, 1, 1, n_light = 2)
   two loops, Yukawas      : 0.420 M_Pl   (at M_V = 30.0 TeV, floor multiples m_J, m_E, m_S = 1, 1, 1, n_light = 2)
   at M_V = 3.755 TeV, all other masses at their floors: 0.612 M_Pl
   With light heavy leptons, N_c = 3 does NOT reach M_Pl in this variant. Heavier M_V
   at fixed fermion masses makes it worse: the light fermions run longer below M_V.

M4  The condition: how heavy the heavy leptons must be (alpha = 1, three loops)
==============================================================================
   M_V =  3.755 TeV: N_c = 3 reaches M_Pl iff m_E >= 0.561 TeV (m_J = 1.3 TeV);  with m_J = m_E tied: m >= 0.858 TeV
   M_V = 10.000 TeV: N_c = 3 reaches M_Pl iff m_E >= 0.963 TeV (m_J = 1.3 TeV);  with m_J = m_E tied: m >= 1.120 TeV
   M_V = 30.000 TeV: N_c = 3 reaches M_Pl iff m_E >= 1.740 TeV (m_J = 1.3 TeV);  with m_J = m_E tied: m >= 1.503 TeV
   m_E = 0.1 TeV at the floors needs g_crit = 6.10 (alpha = 2.96), outside the convergent region (section 3d)
   m_E = 0.3 TeV at the floors needs g_crit = 4.47 (alpha = 1.59), outside the convergent region (section 3d)
   N_c = 5 at the same floors: 1.1e-08 M_Pl (still excluded)
