E5  Is asymptotic freedom of colour needed?  The selection without it
==============================================================================
   The SU(3)_L anomaly alone allows N_g = k N_c (N_c odd) and N_g = 2 k N_c (N_c even).
   Colour's one-loop coefficient is a_3 = -11 N_c/3 + 2 N_g; asymptotic freedom (a_3 < 0)
   is what cuts these to N_g = N_c. Here it is dropped, and every solution is run to
   M_Pl (two loops, no Yukawas, 4 TeV, the measured couplings as for every N_c):
   beta = -1/sqrt3
     N_c = 3, N_g =  3: a = ( 8.67, -6.50, -5.00)  blow-up 2.9e+29 GeV (g = 4 pi), 1.7e+29 (alpha = 1)  above Planck
     N_c = 2, N_g =  4: a = ( 9.33, -6.50,  0.67)  blow-up 1.0e+27 GeV (g = 4 pi), 5.3e+26 (alpha = 1)  above Planck
     N_c = 3, N_g =  6: a = (16.67, -2.50,  1.00)  blow-up 6.5e+15 GeV (g = 4 pi), 4.9e+15 (alpha = 1)  BELOW Planck
     N_c = 4, N_g =  8: a = (26.22,  2.83,  1.33)  blow-up 1.5e+11 GeV (g = 4 pi), 1.3e+11 (alpha = 1)  BELOW Planck
     N_c = 2, N_g =  8: a = (18.00, -2.50,  8.67)  blow-up 4.1e+06 GeV (g = 4 pi), 3.5e+06 (alpha = 1)  BELOW Planck
     N_c = 5, N_g = 10: a = (38.00,  9.50,  1.67)  blow-up 6.0e+08 GeV (g = 4 pi), 5.4e+08 (alpha = 1)  BELOW Planck
   beta = +1/sqrt3
     N_c = 3, N_g =  3: a = (14.00, -6.50, -5.00)  blow-up 3.9e+19 GeV (g = 4 pi), 2.9e+19 (alpha = 1)  above Planck
     N_c = 2, N_g =  4: a = (17.33, -6.50,  0.67)  blow-up 3.0e+16 GeV (g = 4 pi), 2.4e+16 (alpha = 1)  BELOW Planck

     N_c = 4, N_g =  8: a = (39.56,  2.83,  1.33)  blow-up 1.4e+09 GeV (g = 4 pi), 1.3e+09 (alpha = 1)  BELOW Planck
     N_c = 2, N_g =  8: a = (34.00, -2.50,  8.67)  blow-up 4.1e+06 GeV (g = 4 pi), 3.5e+06 (alpha = 1)  BELOW Planck
     N_c = 5, N_g = 10: a = (54.00,  9.50,  1.67)  blow-up 4.3e+07 GeV (g = 4 pi), 3.9e+07 (alpha = 1)  BELOW Planck
   All anomaly solutions with N_c <= 9, N_g <= 4 N_c that reach M_Pl for 3-3-1 scales of
   2-30 TeV, asymptotic freedom not imposed:
     beta = -1/sqrt3 g = 4 pi   (N_c, N_g) = [(2, 4), (3, 3)]
     beta = +1/sqrt3 g = 4 pi   (N_c, N_g) = [(3, 3)]
     beta = -1/sqrt3 alpha = 1  (N_c, N_g) = [(2, 4), (3, 3)]
     beta = +1/sqrt3 alpha = 1  (N_c, N_g) = [(3, 3)]
   -> beta = +1/sqrt3: running alone leaves only (3, 3). beta = -1/sqrt3: (2, 4) also
      reaches M_Pl. Its colour group is not asymptotically free (a_3 = +0.67), but its

      condition of the selection; it is needed only to remove (N_c, N_g) = (2, 4).
      Every other N_g > N_c is already excluded by the running (U(1)_X, or colour itself).
