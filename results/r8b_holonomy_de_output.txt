 Q2  Weak gravity conjecture for U(1)_B' on STUR's circle L
==============================================================================
   electric WGC: a charged state with M_c <= sqrt(2) g4' M_Pl, g4' = 1/(f2 L)
   i.e. M_c L <= sqrt(2) M_Pl / f2.  A charged bulk state of mass M_c
   contributes ~ e^(-M_c L)/L^4 to V2, so V2 = rho_DE needs every charged
   state to have M_c L >= -ln(rho_DE L^4):
     1/L =    9e+02 GeV: M_c L >= 134.4
     1/L =    1e+06 GeV: M_c L >= 162.6
     1/L =    1e+10 GeV: M_c L >= 199.4
     1/L =    4e+12 GeV: M_c L >= 223.4
   rows with w0 < -0.7 have f2 = 0.05-1.01 M_Pl, so WGC
   allows M_c L <= 1.40-27.91.
   -> the WGC state would have M_c L ~ 1 and add ~1/L^4 to V2, more than
      rho_DE by a factor >= 2e+58. Q2 FAILS.
   Escape: a WGC multiplet with exact Bose-Fermi degeneracy cancels in V2;
   it must be degenerate to ~1 part in 1e58, i.e. unbroken bulk
   supersymmetry for that multiplet. Recorded as a loophole, not a pass.
   Conversely f2 small enough for the WGC (f2 <~ sqrt(2)/135 ~ 0.01 M_Pl)
