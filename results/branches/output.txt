B1  The W mass from G_F, M_Z and alpha: what the running of alpha and the top quark do
==============================================================================
   Delta alpha (zero momentum -> M_Z) = 0.05933;  Delta rho (top) = 0.00933, x 0.902 with QCD
   tree level, alpha(0)        : M_W = 80.939 GeV  (+0.71%)
   with alpha run to M_Z       : M_W = 79.961 GeV  (-0.51%)
   with the top quark's loop   : M_W = 80.531 GeV  (+0.20%)
   and its QCD correction      : M_W = 80.474 GeV  (+0.13%)
   measured: 80.3692 +- 0.0133 GeV. The two leading corrections leave +0.13%;
   the remaining bosonic and two-loop terms are not computed (MODEL).
   LIT check: with the PDG's complete Delta r = 0.03685 the same relation gives 80.355 GeV.

B3  Primordial helium: all four forces in one number
==============================================================================
   expansion (gravity): t = 0.75 s at 1 MeV, 119 s at 0.1 MeV; T_nu/T -> 0.7138 ((4/11)^(1/3) = 0.7138)
   weak freeze-out: neutron fraction 0.1602 if neutrons did not decay
   deuterium survives and burns at T = 71 keV, t = 256 s, when the neutron fraction has decayed to 0.1201
   Y_p = 0.2407  (measured 0.245 +- 0.003);  baryons conserved to 5e-14
   D/H left over = 5.7e-05 (measured 2.55e-05): the minimal network leaves twice the
   measured deuterium, since it has no D + p -> 3He. Helium is insensitive to that:
      D + D S-factor x 2    : Y_p = 0.2425
      D + D S-factor / 2    : Y_p = 0.2388
      n + p capture x 1.3   : Y_p = 0.2408
      baryon density + 10%  : Y_p = 0.2415
      lifetime + 5 s        : Y_p = 0.2417
   and to the force that sets the clock: with G 10% larger, Y_p = 0.2491

B5  The electron's magnetic moment and alpha
==============================================================================
   the chain's route, down from M_Z: 1/alpha(0) = 137.0360 +- 0.0088 (the hadronic input's error)
   a_e from that alpha: 0.00115965 +- 0.00000007;  measured 0.00115965218059
   the measured a_e inverted through the QED series: 1/alpha = 137.035999166  (published 137.035999166 +- 1.5e-08)
   they differ by 5.5e-08, far inside the chain's error; the electron's moment is 6e+05 times more precise
   This is a return trip, not an independent test: the alpha-hat(M_Z) that stage 1 takes as input
   was itself obtained from alpha(0). What the branch shows is where the chain's alpha comes from.

B7  The neutron-proton mass difference: quoted, and what it controls
==============================================================================

   delta = 1.3063 MeV: phase space 1.805, lifetime  825.4 s, Y_p = 0.2328
   delta = 1.5100 MeV: phase space 4.481, lifetime  332.4 s, Y_p = 0.1166
   dY_p/d delta = -0.609 per MeV: the measured helium (+- 0.003) fixes delta to +- 5 keV, the lattice to +- 280 keV
