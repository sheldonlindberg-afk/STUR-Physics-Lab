E3  Black-hole entropy from the TEGR action (CHECK)
==============================================================================
   Reference tetrad torsion scalar with this spin connection: 0  (must be 0)
   R = 0, so the action is a boundary flux. e T^r / sin(theta) = -4*M*sqrt(r)/sqrt(-2*M + r) + 3*M + 2*r**(3/2)/sqrt(-2*M + r) - 2*r
   Flux at infinity:          I_inf = 4*pi*M**2   (GR with Gibbons-Hawking + subtraction: beta M / 2 = 4 pi M^2)
   Flux at the horizon tip:   I_tip = 4*pi*M**2
   With the horizon regular (as GR assumes): S = beta M - I_inf = 4*pi*M**2 = A/4 (A = 16 pi M^2): True
   FOLLOWS: the flux at infinity alone gives GR's answer, with no boundary term or
   background subtraction added by hand. The diagonal frame does not rotate around
   the Euclidean horizon, which is singular there and adds an equal flux at the tip.
   A flat frame regular at the tip winds at rate k = -kappa, and then the flux at
   infinity diverges; among frames winding at rate k, only k = 0 is finite there
   (CHECK: stur_tegr_corner K5).
   So TEGR gives A/4 with the same input as GR (a smooth horizon), not with less.
   LIT: the same result, and its charged and Lambda != 0 versions, is in Kuntz, Paci,
   Zanusso, arXiv:2410.04510, and Beltran Jimenez, Koivisto, arXiv:2412.13946.

E4  The gravitational phase as a TEGR holonomy; the FIELD's own share
==============================================================================
   A mass on a worldline picks up phase -(m c / hbar) int e^0_mu dx^mu: the
   holonomy of the translational potential B^0_0 = Phi / c^2 (KNOWN; COW 1975,
   gravitational Aharonov-Bohm: Overstreet et al., Science 375, 226 (2022)).
   Two diamonds (1.468e-14 kg, 181 um): matter part +1.587e-34 J, field part -7.937e-35 J, total L = +7.937e-35 J = G m^2 / r
   FOLLOWS: the matter coupling alone would give 2 G m^2 / r; the gravitational FIELD's
   own action gives -G m^2 / r, and the net is the familiar G m^2 / r. The field term
   is not optional: without it the phase is doubled. For it to depend on the branch
   pair, the field configuration itself must be in two places.
   So in TEGR language: lambda = 1 means the torsion field is in two places, exactly
   as the electron's EM field is (T5). lambda = 0 means one torsion field.

   no analogue of that surface and cannot be screened.

E7  What TEGR changes for the experiment
==============================================================================
   Predictions: nothing. T = -R + B (E1), so lambda = 1 vs lambda = 0, the phases,
   the noise budget and the design (GRAVITY_ENTANGLEMENT.md) are all unchanged.
   What it changes is the reading:
    - gravity is a gauge FORCE field (torsion) on flat spacetime, the same structure
      as electromagnetism. The split-vs-amplitude question becomes the SAME question
      for both fields. EM answers lambda = 1 (T5); TEGR's linear theory is an abelian
      gauge theory like EM, which makes lambda = 1 the structural expectation.
      (Expectation, not proof: the experiment still decides.)
    - the field's own action is part of the entangling phase (E4).
    - the translational potential is an abelian gauge connection (E5).
   Not used: f(T) and other modified teleparallel theories, which DO change
   predictions but add new structure.
