 9A  Can a STUR-ROLL discrete symmetry fix |V_us|?
==============================================================================
   Bulk quarks: a chiral zero mode needs the same orbifold parity at both
   branes. The brane angle vartheta = pi multiplies the y = 0 parity by
   (-1)^q, so a field with odd q has NO zero mode (its lightest mode sits
   at the KK scale). Chiral quarks therefore need q even: vartheta = pi acts
   as +1 on every quark. The orbifold parity of each zero mode is fixed by
   its chirality, the same for every generation. The Z6 centre is part of
   the gauge group and acts identically on all generations.
   -> bulk quarks: every generation carries identical discrete charges;
      all 9 Yukawa entries are allowed in each sector.

   Brane-localised quarks escape the zero-mode condition, so vartheta's
   (-1)^q can differ between generations. Enumerating every assignment
   q in {0,1} for Q_i, u_i, d_i and the Higgs (2^10 = 1024):
     some quark massless (excluded):      912
     |V_us| varies with the couplings:    104
     |V_us| fixed by the symmetry:        8  -> values [np.float64(0.0)]
   -> abelian Z2 charges either leave |V_us| continuous or pin it to an
      endpoint (only 0 occurs here); they never fix a value in between.
      9A: NO-GO (as preregistered).
