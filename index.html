STUR Physics Lab

One simulation. Nothing tuned.

One Python file that uses only the standard library. Every number it prints is calculated from measured inputs. Measured results are used only to judge the output, never inside a calculation. Where the inputs cannot fix a quantity, the script scans its whole range instead of choosing a value.

Download .py View on GitHub

Paste it into any Python 3.8+ runner, notebook or AI assistant's code tool. It runs in about 5 seconds and ends with 15 self-checks. Expected output: results/production_v2_2.txt.

The rule

  • INPUTS: measured or defined constants, each with an uncertainty and a source (PDG 2024, Planck 2018, CODATA, SI).
  • COMPARISONS: measured results, used only to judge the output.
  • NUMERICS: step counts, grid sizes and precision. The self-checks vary them and show the results do not move.
  • Everything else is calculated. The repository's test fails if any non-integer number appears in the script outside those three tables.

Part B: quark mixing from quark masses

The six measured quark masses are run with the renormalization group up to the 3-3-1 benchmark scales (1.5 to 10 TeV). Every coefficient is computed from group theory. The masses fix every entry of the Fritzsch six-zero texture, and diagonalizing both sectors exactly gives the CKM matrix. The texture's two phases are fixed by nothing, so each prediction is the band swept out over all of their values.

Result: with nothing tuned, the quark masses give the Cabibbo angle, |Vub| and the size of CP violation, but for no value of the phases do they give |Vcb|. The six-zero texture is excluded, as the literature also finds.
