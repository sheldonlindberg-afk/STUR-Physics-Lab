1. STUR Field Equation → Hydrothermal Vent Model

STUR is Sheldon's Theory of Unified Resistance. The fundamental object is a unified resistance field R(x,t,X) defined on a 5D manifold: three spatial coordinates, physical time t, and an internal coordinate X that carries the “missing” deterministic information (coherence, memory, feedback) that gets projected away in standard 4D physics.

R = R(x,t,X) unified resistance field ∂R/∂t = ∇·(D∇R) − ∇R · Ω + χ ∂R/∂X + S STUR evolution law ∂R/∂X = (R − R_bg) / L_X X-coupled resistance manifold G_ab = ∂_a R ∂_b R + g_ab V(R) curvature from resistance gradients

In this specific lab we focus on a single alkaline hydrothermal micro-pore. We ignore bulk fluid vorticity Ω and group the detailed source terms into a reaction–diffusion description for a small set of chemical fields: CO₂, H₂, an acetyl-thioester analogue Ac, and an ATP-like phosphate potential. The pore provides: a vertical temperature gradient, a proton (pH) gradient, redox energy via H₂/CO₂, and catalytic FeS/NiS walls.

The resistance field is constructed from these chemical fields:

R(x,t) = w_CO2 · [CO2](x,t) + w_H2 · [H2](x,t) + w_Ac · [Ac](x,t) + w_ATP · [ATP](x,t) + w_Fe · [Fe²⁺](x,t) R_bg(t) = ⟨R(x,t)⟩_volume ∂R/∂X ≈ (R − R_bg)/L_X f_X(x,t) = exp[ χ_X · (R(x,t) − R_bg(t)) ] (clamped numerically)

The X-dimension is not simulated explicitly as a new axis. Instead, the discrete map ∂R/∂X ≈ (R−R_bg)/L_X is folded into the reaction rates through f_X, which is exactly how STUR shows up in the PDEs below.

The chemical evolution in the pore (schematic) is:

∂[Ac]/∂t = D_Ac ∇²[Ac] − v_th(z) ∂[Ac]/∂z + r_form([CO2],[H2],[Ac],T,pH) · f_X − λ_Ac [Ac] ∂[CO2]/∂t = D_CO2 ∇²[CO2] − r_form ∂[H2]/∂t = D_H2 ∇²[H2] − r_form ∂[ATP]/∂t = D_ATP ∇²[ATP] + y_ATP · r_form − λ_ATP [ATP]

with the catalytic formation term

r_form = surface(x,y) · k_cat(T) · f_pH(pH) · f_X(R−R_bg) · [CO2] · [H2] · ([Ac] + ε) k_cat(T) = k_base · exp[ −E_a/R_g (1/T − 1/T_ref) ] f_pH = exp[ −α (pH − pH_opt)² ] surface ≈ 1 + O(10–40×) near FeS/NiS-like walls v_th(z) = − D_Ac S_T · ∂T/∂z / T (thermophoresis, Soret effect)

The scripts below implement exactly these equations on a cubic grid embedding a cylindrical micro-pore with a 12 µm height/diameter, 80–120 °C vertical temperature gradient, and a pH gradient from ≈ 9.8 (alkaline interior) to ≈ 6 (external ocean side). STUR enters only through the curvature-sensitive feedback factor f_X, which elevates regions with large resistance curvature into stable, self-sustaining proto-cell-like attractors.

Starting from the STUR evolution law, we can make the reduction explicit. Take R(x,t) = Σ_i w_i c_i(x,t) with species c_i ∈ { [CO2],[H2],[Ac],[ATP],[Fe²⁺] }. Then

∂R/∂t = Σ_i w_i ∂c_i/∂t STUR: ∂R/∂t = ∇·(D∇R) + χ ∂R/∂X + S_eff Assume Ω ≈ 0 (no large-scale vorticity in the micro-pore frame) and absorb detailed chemistry and boundary exchange into S_eff.

Substituting the reaction–diffusion form for each species, ∂c_i/∂t = D_i ∇²c_i + F_i(c,T,pH,R), we obtain

∂R/∂t = Σ_i w_i D_i ∇²c_i + Σ_i w_i F_i(c,T,pH,R) ∇·(D∇R) ≈ Σ_i w_i D_i ∇²c_i (effective diffusion for R) χ ∂R/∂X = χ (R − R_bg)/L_X = χ/L_X · (R − R_bg)

Matching terms gives a consistency condition: the net reaction contribution Σ_i w_i F_i must equal the combination of STUR source terms S_eff + χ(L_X^{-1})(R−R_bg). In the vent scripts, we enforce this by inserting the X-feedback factor f_X = exp[ χ (R − R_bg) ] directly into the catalytic rate r_form. High-resistance regions (relative to the volume average) receive an exponential gain in formation rate, which is exactly the curvature selection:

F_Ac ⊃ r_form · f_X ⇒ ∂[Ac]/∂t ⊃ r_form · exp[χ (R − R_bg)] large (R − R_bg) → large f_X → local growth small (R − R_bg) → f_X ≈ 1 → background mixing

The discrete scheme used in the scripts is a standard explicit finite-difference / upwind discretization of the PDEs. For a generic scalar field c(x,t) with diffusion coefficient D, drift velocity v_z, and reaction term F(c):

c^{n+1} = c^n + Δt · D ∇²_h c^n − Δt · v_z · (c^n − c^n_from_upwind)/Δz + Δt · F(c^n) ∇²_h c(i,j,k) = [c(i+1,j,k)+c(i−1,j,k)+c(i,j+1,k)+c(i,j−1,k)+c(i,j,k+1)+c(i,j,k−1)−6c(i,j,k)] / Δx²

Stability of the explicit diffusion step is enforced by choosing dt ≈ 0.2–0.25 · dx² / max(D_i), which is encoded directly in dt = 0.25 * dx*dx / max(...) in the FAST script and similarly in the FULL script. The advective CFL constraint is mild here because v_th is small relative to dx/dt, but the upwind form adds extra numerical damping and helps maintain stability as χ and gradients grow.

Finally, the JSON outputs stur_vent_fast.json and stur_vent_full.json store:

{ "mode": "FAST" or "FULL", "grid": [N,N,N], "dx_m": Δx in meters, "dt_s": Δt in seconds, "nt": total steps, "T_hot_K": upper temperature, "T_cold_K": lower temperature, "pH_top": alkaline side, "pH_bottom": acidic side, "chi_values": [χ_1, χ_2, ...], "bifurcation_results": [ { "chi_X": χ, "Ac_final": ⟨[Ac]⟩_final, "R_var_max": max_t Var(R − R_bg) }, ... ], "example_history": { "chi_X": χ_example, "t_s": [t_0, ..., t_n], "Ac_mean": [...], "ATP_mean": [...], "R_var": [...] } }

That means the “physics result” of the run is fully encoded as numbers: given only the JSON, any external code can reconstruct the bifurcation curve, track the emergence of localized proto-cell states as χ increases, and cross-check every parameter of the STUR vent model without touching this HTML file.

2. How to Run This STUR Lab

1. Open JupyterLab in your browser: https://jupyter.org/try-jupyter/lab/
2. Create a new Python notebook or Python file.
3. Copy either the FAST or FULL script below into a cell (or file).
4. Run the cell. The simulation will execute and write a JSON file: stur_vent_fast.json or stur_vent_full.json.
5. Use the JSON to make bifurcation plots, phase diagrams, or to audit every parameter.

3. FAST MODE – 32³ Grid (JupyterLite-Safe)

This version is tuned for speed on JupyterLite and laptops. It uses a 32³ grid with realistic vent parameters and full STUR curvature feedback. It sweeps several χX values, prints the final acetyl means and resistance variance, and writes a compact JSON diagnostic file stur_vent_fast.json with the bifurcation data and an example time series.

4. FULL PHYSICS MODE – 96³ Grid (Publication-Grade)

This version pushes resolution to 96³ and is appropriate for publication figures and serious parameter sweeps. It uses tighter, more realistic concentrations and the same STUR-driven feedback. It writes stur_vent_full.json with grid, dt, χ sweep results, and an example χX trajectory for full forensic reproducibility.

5. Interpretation and STUR Bifurcation

As you sweep χX from 0 upward, both scripts produce a clear transition: for low χX the vent is just a gradient-driven mixer with diffuse acetyl; for χX ≈ 3.5–4.5 the STUR curvature term amplifies resistance hotspots and nucleates stable, localized acetyl/ATP structures that behave like proto-cells riding the ΔT and ΔpH gradients. All of that is encoded in the JSON, so anyone can regenerate the curves, slices, and statistics without trusting the plots or the text.
