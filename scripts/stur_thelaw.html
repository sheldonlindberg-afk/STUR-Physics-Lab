Core Field Equation

The Law of Resistance – one equation for motion, structure, and life.

STUR models the universe with a single resistance field $R(x,t,X)$ defined on a 5D manifold. Everything else – diffusion, drift, memory, curvature, probability, emergence – falls out of how $R$ evolves in space, time, and the hidden feedback dimension $X$.

STUR evolution law
\[ \frac{\partial R}{\partial t} = \nabla \cdot (D \nabla R) - \nabla R \cdot \Omega + \chi \frac{\partial R}{\partial X} + S \]
This is a conservation law for resistance: local changes in $R$ come from diffusion, directed flow, hidden-dimension feedback, and external sources.
Plain language summary
Every system pushes through a landscape of resistance $R$. Gradients in that landscape determine what moves, what forms, and what survives: matter, fields, code, markets, cells, and minds all follow the same rule: they flow down resistance gradients while feedback in $X$ writes memory and coherence.
Term legend
R(x,t,X): resistance field D: diffusion tensor Ω: drift / flow field χ: X-coupling strength S: sources / sinks

The hidden dimension $X$ carries feedback, adaptation, and internal state. When you drop $X$, the universe looks probabilistic. When you keep it, it becomes deterministic.

1 · Deriving the Law of Resistance

From conservation law → STUR 5D evolution equation

Start with the only assumption you really need: there is a scalar resistance field $R(x,t,X)$ defined over physical space $x$, time $t$, and a hidden feedback coordinate $X$.

Local resistance balance
\[ \frac{\partial R}{\partial t} + \nabla \cdot J_R = S. \]

Here $J_R$ is the resistance flux and $S$ collects all sources and sinks. To turn this balance into a working PDE, you specify how $J_R$ is built from $R$.

Step 1 – Diffusion down gradients

Systems smooth out sharp spikes in resistance. This gives \[ J_{\text{diff}} = -D \nabla R \] and therefore

\[ \frac{\partial R}{\partial t} = \nabla \cdot (D \nabla R) + \dots \]

Step 2 – Drift along a flow field

Add directed transport: \[ J_{\text{flow}} = R \Omega \] which yields the drift term

\[ -\nabla R \cdot \Omega. \]

Step 3 – Hidden-dimension feedback

Promote coherence/history into a coordinate $X$:

X-coupled resistance manifold
\[ \frac{\partial R}{\partial X} = \frac{R - R_{bg}}{L_X}. \]

This feeds back into time evolution through $\chi \partial R/\partial X$.

Step 4 – Collect everything

Combine all pieces:

\[ \frac{\partial R}{\partial t} = \nabla \cdot (D \nabla R) - \nabla R \cdot \Omega + \chi \frac{\partial R}{\partial X} + S. \]

3 · Proof of concept: resistance smoothing in 1D

A minimal numerical experiment inside the page

Switch off flow, X-feedback, and sources to view the pure diffusion limit:

1D diffusion limit
\[ \frac{\partial R}{\partial t} = D \frac{\partial^2 R}{\partial x^2}. \]

Below is the minimal 1D JS demo. 

 
# STUR 1D Resistance Diffusion – Jupyter-Compatible Full Demo
# Runs in JupyterLite / JupyterLab with numpy + matplotlib only

import numpy as np
import matplotlib.pyplot as plt
import json

# -------------------------------------------------------------
# Parameters
# -------------------------------------------------------------
N = 64          # grid points
D = 0.2         # diffusion coefficient
dx = 1.0        # spatial step
dt = 0.1        # time step (stable)
steps = 200     # number of iterations

# -------------------------------------------------------------
# Initial resistance profile: sharp spike at center
# -------------------------------------------------------------
R = np.zeros(N)
center = N // 2
for i in range(N):
    dist = abs(i - center)
    R[i] = 1.0 if dist < 3 else 0.0

initialR = R.copy()

# -------------------------------------------------------------
# Finite-difference evolution loop for:
#       ∂R/∂t = D ∂²R/∂x²
# -------------------------------------------------------------
for _ in range(steps):
    newR = R.copy()
    lap = (np.roll(R, -1) - 2 * R + np.roll(R, 1)) / (dx * dx)
    newR = R + dt * D * lap
    R = newR

finalR = R.copy()

# -------------------------------------------------------------
# JSON-like dump for the webpage output box
# -------------------------------------------------------------
def rlist(arr):
    return [float(f"{x:.3f}") for x in arr]

payload = {
    "description": "1D STUR diffusion demo of the Law of Resistance",
    "equation": "dR/dt = D d²R/dx²",
    "N": N,
    "D": D,
    "dx": dx,
    "dt": dt,
    "steps": steps,
    "initial_R_center_slice": rlist(initialR),
    "final_R_center_slice": rlist(finalR),
}

print(json.dumps(payload, indent=2))

# -------------------------------------------------------------
# Plot initial vs final resistance profiles
# -------------------------------------------------------------
plt.figure(figsize=(10,5))
plt.plot(initialR, label="Initial R", linewidth=2)
plt.plot(finalR, label="Final R", linewidth=2)
plt.title("STUR 1D Resistance Diffusion")
plt.xlabel("Space index")
plt.ylabel("R value")
plt.grid(True)
plt.legend()
plt.tight_layout()
plt.show()
