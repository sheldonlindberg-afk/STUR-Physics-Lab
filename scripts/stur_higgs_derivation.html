1. The Fifth Component of the Gauge Field

1.1 5D Gauge Field Decomposition

The 5D gauge field AM decomposes under 4D Lorentz symmetry as:

\[A_M = (A_\mu, A_5) \quad \text{where } \mu = 0,1,2,3\]
(1.1)

Under 4D Lorentz transformations:

  • Aμ transforms as a 4D vector (spin-1)
  • A5 transforms as a 4D scalar (spin-0)
Key Observation

The fifth component A5 is automatically a 4D scalar field. No new field needs to be introduced.

1.2 Z2 Parity Assignment

On the orbifold S1/Z2, fields must have definite parity under X → -X.

For the gauge field, consistency with gauge invariance requires:

\[\boxed{A_\mu(x, -X) = P A_\mu(x, X) P^{-1}, \quad A_5(x, -X) = -P A_5(x, X) P^{-1}}\]
(1.2) — Z2 parity assignment

where P is the parity matrix acting on gauge indices.

2. The Higgs Potential from Geometry

2.1 Coleman-Weinberg Mechanism

The boundary mode A5 = H has no classical potential (protected by 5D gauge invariance). However, quantum corrections generate an effective potential:

\[\boxed{V_{\rm eff}(H) = \sum_n c_n \frac{(-1)^{F_n}}{(4\pi)^2} m_n^4(H) \ln\frac{m_n^2(H)}{\mu^2}}\]
(2.1) — Coleman-Weinberg potential

where mn(H) are the H-dependent masses of particles running in loops.

2.2 Contribution from Gauge Bosons

The W and Z bosons get mass from H:

\[m_W^2(H) = \frac{g_2^2}{4} |H|^2, \quad m_Z^2(H) = \frac{g_2^2 + g_1^2}{4} |H|^2\]
(2.2)

Their contribution to Veff is positive definite at H = 0, favoring symmetry breaking.

2.3 Contribution from Top Quark

The top quark Yukawa coupling gives:

\[m_t^2(H) = y_t^2 |H|^2\]
(2.3)

Fermion loops contribute with opposite sign (Fn = 1), destabilizing the origin.

2.4 The Mexican Hat Emerges

Summing contributions:

\[\boxed{V_{\rm eff}(H) = -\mu^2 |H|^2 + \lambda |H|^4 + O(|H|^6)}\]
(2.4) — Mexican hat potential (derived!)

where:

\[\mu^2 = \frac{3}{64\pi^2 L_X^2} (3g_2^4 + 2g_2^2 g_1^2 + g_1^4 - 4y_t^4) > 0\]
(2.5a) — Mass parameter from geometry
\[\lambda = \frac{1}{16\pi^2} (3g_2^4 + 2g_2^2 g_1^2 + g_1^4 - 4y_t^4 + \ldots)\]
(2.5b) — Quartic coupling from geometry
Result: EWSB Is Radiatively Generated

The negative mass-squared μ² < 0 arises because the top quark loop (negative) dominates over gauge loops (positive). This is NOT assumed—it is calculated from the spectrum.

3. Determining the Higgs VEV

3.1 Minimization Condition

The VEV is determined by:

\[\frac{dV_{\rm eff}}{d|H|} = 0 \quad \Rightarrow \quad v^2 = \frac{\mu^2}{\lambda}\]
(3.1)

3.2 Connection to LX

Both μ² and λ depend on LX. Explicitly:

\[\boxed{v = \frac{c_v}{L_X}, \quad c_v = O(1) \text{ dimensionless constant}}\]
(3.2) — VEV from orbifold size

For v = 246 GeV, this requires:

\[L_X \sim \frac{c_v}{246\, \text{GeV}} \sim 10^{-17}\, \text{m} \quad \text{(GUT scale)}\]
(3.3)

3.3 Higgs Mass Prediction

The Higgs mass is:

\[\boxed{m_H^2 = 2\lambda v^2 = \frac{v^2}{8\pi^2} (3g_2^4 + 2g_2^2 g_1^2 + g_1^4 - 4y_t^4)}\]
(3.4) — Higgs mass from gauge couplings

With SM values at the weak scale:

\[m_H \approx 115 - 150\, \text{GeV}\]
(3.5)

The observed value mH = 125 GeV is within this range. More precise calculation requires 2-loop corrections.
