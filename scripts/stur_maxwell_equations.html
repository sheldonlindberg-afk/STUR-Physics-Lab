3. Deriving Maxwell's Equations

3.1 The Full Action with Sources

3.2 Euler-Lagrange Equations

Varying with respect to Aν:

\[\frac{\delta S}{\delta A_\nu} = 0 \quad \Rightarrow \quad \partial_\mu \Tor{F^{\mu\nu}} = \Matt{j^\nu}\]
(3.2)
Full Derivation: Euler-Lagrange for Gauge Fields Intermediate

The Lagrangian density is:

\[\mathcal{L} = -\frac{1}{4}F_{\mu\nu}F^{\mu\nu} - j^\mu A_\mu\]

Using Fμν = ∂μAν - ∂νAμ:

\[\frac{\partial \mathcal{L}}{\partial A_\nu} = -j^\nu, \quad \frac{\partial \mathcal{L}}{\partial(\partial_\mu A_\nu)} = -F^{\mu\nu}\]

The Euler-Lagrange equation gives:

\[\partial_\mu \frac{\partial \mathcal{L}}{\partial(\partial_\mu A_\nu)} - \frac{\partial \mathcal{L}}{\partial A_\nu} = 0 \quad \Rightarrow \quad -\partial_\mu F^{\mu\nu} + j^\nu = 0\]
