The orbifold S1/Z2 has two fixed points at X = 0 and X = LX. The Z2 action acts on the 5D gauge field AM as:

\[\boxed{A_\mu(x, -X) = P\, A_\mu(x, X)\, P^{-1}, \quad A_5(x, -X) = -P\, A_5(x, X)\, P^{-1}}\]
(1.1) — Z2 parity assignment

where P ∈ G is the parity matrix satisfying P2 = 1. This decomposes the gauge group as:

\[\Quant{G} \;\xrightarrow{\text{orbifold}}\; \Quant{G_+} \times \Quant{G_-}\]

where G+ (even) survives as 4D gauge bosons and G- (odd) becomes massive.

Constraint 1.1 — Rank Preservation

The 4D gauge group G4D = G+ must have the same rank as G5D. This follows because the Cartan subalgebra generators must be Z2-even to give massless gauge bosons.

\[\text{rank}(\Quant{G_{4D}}) = \text{rank}(\Quant{G_{5D}})\]
(1.2)

The kink profile ensures:

3. Anomaly Cancellation from Geometric Consistency

Key Theorem: Anomaly Cancellation Is Derived, Not Input

On the orbifold M4 × S1/Z2, anomaly cancellation is a geometric consistency condition, not a separate physical requirement. The path integral measure is well-defined if and only if all gauge anomalies vanish. This follows directly from Axiom 1 — no additional input is needed.

3.1 Why Anomaly Cancellation Is Geometric

The Master Action (Axiom 1) defines the theory on M4 × S1/Z2. For this theory to exist mathematically:

Step 1: Path integral must be well-defined
The partition function Z = ∫𝒟ψ 𝒟A exp(iS) requires a gauge-invariant measure 𝒟ψ.
Step 2: Measure transforms under gauge
Under a gauge transformation, 𝒟ψ → 𝒟ψ · exp(iΓ[A]) where Γ is the anomaly functional.
Step 3: Gauge invariance requires Γ = 0
For Z to be gauge-invariant, we need Γ[A] = 0. This is the anomaly cancellation condition.
Step 4: This is not input — it's existence
If Γ ≠ 0, the theory defined by Axiom 1 does not exist. Anomaly cancellation is a consistency condition of the axiom, not a separate assumption.
\[\boxed{\text{Axiom 1 well-defined} \;\Leftrightarrow\; \Gamma[A] = 0 \;\Leftrightarrow\; \text{Anomalies cancel}}\]
(3.0) — Anomaly cancellation is geometric consistency
