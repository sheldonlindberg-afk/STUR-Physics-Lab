STUR Geometry in One Equation

S(r) = tanh(r/L₀) · (1 − e−r/L₀)

This one expression contains curvature, damping, confinement characteristics, and the ability to unify different types of fields into one geometry.

In the Python template below, this same S(r) is used to build a 1D → 5D radial motion suite: same geometry, different dimensional labels.

# ===============================================================
# STUR 1D → 5D Manifold Starter – AI + Human Loop
# - JupyterLite-safe: numpy + matplotlib + json only
# - Geometry: S(r) = tanh(r/L0) * (1 - exp(-r/L0))
# - Dynamics: simple radial motion in that geometry
# ===============================================================

import numpy as np
import matplotlib.pyplot as plt
import json

plt.style.use("dark_background")

# -------------------------------
# 1. Geometry and its derivative
# -------------------------------
def S(r, L0=1.0):
    """
    STUR-style scalar geometry in terms of radius r.
    L0 sets the characteristic length / curvature scale.
    """
    x = r / L0
    return np.tanh(x) * (1.0 - np.exp(-x))


def dS_dr(r, L0=1.0):
    """
    Analytic derivative of S with respect to r.
    This is where the "force" comes from: F(r) = -dS/dr.
    """
    x = r / L0
    sech2 = 1.0 / np.cosh(x)**2
    return (sech2 * (1.0 - np.exp(-x)) + np.tanh(x) * np.exp(-x)) / L0


def force(r, L0=1.0):
    """
    Effective radial force for the toy model.
    More realistic systems will add angular terms, charges, etc.
    """
    return -dS_dr(r, L0)

# -------------------------------
# 2. Single radial step
# -------------------------------
def radial_step(r, v, dt, L0=1.0, damping=0.05):
    """
    Euler update for radial motion in the STUR geometry.
      r ... radius
      v ... radial velocity
      dt ... time step
      damping ... simple velocity drag term
    """
    F = force(r, L0)
    v = v + (F - damping * v) * dt
    r = r + v * dt

    # hard-wall reflections at r = 0
    if r < 0.0:
        r = 0.0
        v *= -0.4

    return r, v

# -------------------------------
# 3. Dimension-labeled simulation
# -------------------------------
def simulate_dimension(D, L0=1.0, Rmax=5.0, dt=0.01, steps=4000):
    """
    Simulate radial motion for a given "dimension label" D.

    For now, D is a label, not full coordinate geometry.
    The point is to show that **the same S(r)** can underlie
    1D, 2D, 3D, 4D, 5D systems, just with different physical
    interpretations.

    Ask AI to:
      - Replace this radial toy model with full D-dimensional
        coordinates (x, y, z, t1, t2) for STUR 5D.
      - Map each D to a real system (string, membrane, orbit, etc.).
    """
    r = 0.6 * Rmax
    v = 0.0
    rs = []

    for _ in range(steps):
        r, v = radial_step(r, v, dt, L0=L0)
        # keep the particle inside a box [0, Rmax]
        r = float(np.clip(r, 0.0, Rmax))
        rs.append(r)

    rs = np.array(rs)
    summary = {
        "D": int(D),
        "L0": float(L0),
        "Rmax": float(Rmax),
        "r_min": float(rs.min()),
        "r_max": float(rs.max()),
        "r_mean": float(rs.mean())
    }
    return rs, summary

# -------------------------------
# 4. Run the 1D → 5D suite
# -------------------------------
def run_suite(max_dim=5, L0=1.0, Rmax=5.0, dt=0.01, steps=4000):
    """
    Run the same radial experiment for D = 1, 2, 3, 4, 5.
    Returns both trajectories and a compact JSON summary.
    """
    all_traj = {}
    summaries = []
    for D in range(1, max_dim + 1):
        rs, summary = simulate_dimension(D, L0=L0, Rmax=Rmax, dt=dt, steps=steps)
        all_traj[D] = rs
        summaries.append(summary)
    return all_traj, summaries

# -------------------------------
# 5. Main: plot + JSON + prompt
# -------------------------------
if __name__ == "__main__":
    L0 = 1.0
    Rmax = 5.0
    max_dim = 5

    trajs, summaries = run_suite(max_dim=max_dim, L0=L0, Rmax=Rmax)

    # --- Plot all dimensions on one figure ---
    fig, ax = plt.subplots(figsize=(8, 6))
    # Use the shortest trajectory length for the time axis
    min_len = min(len(rs) for rs in trajs.values())
    t = np.arange(min_len)

    for D, rs in trajs.items():
        ax.plot(t, rs[:min_len], label=f"{D}D")

    ax.set_xlabel("time step")
    ax.set_ylabel("radius r")
    ax.set_title("STUR radial motion across 1D → 5D manifold")
    ax.legend()
    plt.tight_layout()
    plt.show()

    # --- Save JSON summary for downstream AI use ---
    with open("stur_1D_to_5D_summary.json", "w") as f:
        json.dump(summaries, f, indent=2)

    print("=== STUR 1D → 5D MANIFOLD SUITE ===")
    print(json.dumps(summaries, indent=2))

    # --- Hand the baton to the human + AI loop ---
    print("\nNext prompt for your AI co-pilot:\n")
    print(
        "Take this 1D–5D STUR manifold summary and:\n"
        "1) propose a concrete physics problem (oscillator, orbit, plasma, etc.),\n"
        "2) derive the corresponding Lagrangian or Hamiltonian in this geometry,\n"
        "3) write a new JupyterLite-safe simulation that tests a falsifiable prediction."
    )

    # You can literally copy-paste the printed text above into your next AI chat.
    # That is the hand-off: simulation → AI → new theory / experiment.
