3 Numerical Methods

Translating PDEs to code requires careful discretization. We implement Crank-Nicolson - a semi-implicit method that's unconditionally stable.

Why Not Explicit Euler?

Simple forward Euler has a strict stability limit (CFL condition):

\[\Delta t < \frac{(\Delta x)^2}{2D} \quad \text{(explicit stability limit)}\]

This forces tiny timesteps for fine grids. Crank-Nicolson removes this restriction.

Crank-Nicolson: Semi-Implicit Averaging

Average the spatial operator between time levels \(n\) and \(n+1\):

\[\frac{R_i^{n+1} - R_i^n}{\Delta t} = \frac{1}{2}\Big[\mathcal{L}(R^n) + \mathcal{L}(R^{n+1})\Big]\]
Unconditionally stable for diffusion

This yields a tridiagonal system \(\mathbf{A}\cdot R^{n+1} = \mathbf{b}\), solved efficiently via Thomas algorithm.

Code Pattern: Thomas Algorithm (TDMA)

// Solve: a[i]*x[i-1] + b[i]*x[i] + c[i]*x[i+1] = d[i]
function solveTridiagonal(a, b, c, d) {
  const n = d.length;
  const cp = new Float64Array(n);  // c-prime
  const dp = new Float64Array(n);  // d-prime
  const x  = new Float64Array(n);  // solution

  // Forward sweep
  cp[0] = c[0] / b[0];
  dp[0] = d[0] / b[0];
  for (let i = 1; i < n; i++) {
    const m = 1 / (b[i] - a[i] * cp[i-1]);
    cp[i] = c[i] * m;
    dp[i] = (d[i] - a[i] * dp[i-1]) * m;
  }

  // Back substitution
  x[n-1] = dp[n-1];
  for (let i = n-2; i >= 0; i--) {
    x[i] = dp[i] - cp[i] * x[i+1];
  }
  return x;
}
