1. Overview: λ is Derived, Not Postulated

Key Claim

2. X-Mode Quantization on S¹/Z₂

2.1 Orbifold Structure

The internal dimension is the orbifold \(\XCRM{S^1/\mathbb{Z}_2}\) — a circle of circumference \(2\XCRM{L_X}\) with points identified under the Z₂ reflection \(X \leftrightarrow -X\). This creates an interval \(X \in [0, \XCRM{L_X}]\) with fixed points at the boundaries.

2.2 Mode Expansion

The resistance field \(\Diff{R(x^\mu, X)}\) is Z₂-odd (\(\Diff{R}(-X) = -\Diff{R}(X)\)), which forces:

\[\boxed{\Diff{R}(x^\mu, X) = \sum_{n=1}^{\infty} \Diff{R_n}(x^\mu) \cdot \sin\!\left(\frac{n\pi X}{\XCRM{L_X}}\right)}\]
(2.1) — X-mode expansion (Z₂-odd)

The cosine modes are excluded by the Z₂ parity, leaving only sine modes with \(n = 1, 2, 3, \ldots\)

2.3 Mode Energies

The kinetic energy in the X-direction gives each mode a mass:

\[m_n = \frac{n\pi}{\XCRM{L_X}} \quad \Rightarrow \quad E_n^{(0)} = \frac{n\pi \hbar c}{\XCRM{L_X}}\]
(2.2) — Free mode energies (Kaluza-Klein tower)

The ratio of consecutive mode energies in the free theory is simply:

\[\frac{E_{n+1}^{(0)}}{E_n^{(0)}} = \frac{n+1}{n}\]
(2.3) — Free energy ratio

3. XCRM Mode Mixing

3.1 The Mixing Term

The XCRM coupling \(\XCRM{\chi R \partial_X R}\) introduces mixing between different X-modes. Substituting the mode expansion:

\[\XCRM{\chi R \partial_X R} = \XCRM{\chi} \sum_{m,n} \Diff{R_m R_n} \sin\!\left(\frac{m\pi X}{\XCRM{L_X}}\right) \cdot \frac{n\pi}{\XCRM{L_X}} \cos\!\left(\frac{n\pi X}{\XCRM{L_X}}\right)\]
(3.1) — XCRM term in mode expansion

3.2 Overlap Integrals

Integrating over \(X \in [0, \XCRM{L_X}]\) picks out specific mode combinations:

\[I_{mn} = \int_0^{L_X} \sin\!\left(\frac{m\pi X}{L_X}\right) \cos\!\left(\frac{n\pi X}{L_X}\right) dX\]
(3.2) — Mode overlap integral

Using the identity \(\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]\):

\[\boxed{I_{mn} = \begin{cases} \dfrac{2m}{\pi(m^2-n^2)} & \text{if } m+n \text{ is odd} \\[8pt] 0 & \text{if } m+n \text{ is even} \end{cases}}\]
(3.3) — Selection rule for XCRM mixing
Selection Rule

XCRM mixing only couples modes with \(m + n\) = odd. This means:
• Mode 1 couples to modes 2, 4, 6, ...
• Mode 2 couples to modes 1, 3, 5, ...
• The ground state (n=1) primarily mixes with the first excited state (n=2)

4. Energy Shifts and Mode Ratios

4.1 Perturbative Correction

To first order in perturbation theory, the XCRM coupling shifts the mode energies:

\[\Delta E_n = \sum_{m \neq n} \frac{|\langle m | H_{\rm XCRM} | n \rangle|^2}{E_n^{(0)} - E_m^{(0)}}\]
(4.1) — Second-order energy shift

For the lowest modes (n = 1, 2), the dominant mixing is with adjacent modes:

\[E_1 \approx E_1^{(0)} + \XCRM{\chi}^2 \cdot \frac{|I_{12}|^2}{E_1^{(0)} - E_2^{(0)}} + \ldots\] \[E_2 \approx E_2^{(0)} + \XCRM{\chi}^2 \cdot \frac{|I_{21}|^2}{E_2^{(0)} - E_1^{(0)}} + \ldots\]
(4.2) — Lowest mode energy shifts

4.2 Dominant Contribution

The largest overlap integral involving the ground state is:

\[I_{12} = \frac{2 \cdot 1}{\pi(1^2 - 2^2)} = -\frac{2}{3\pi}\]
(4.3) — Ground state mixing coefficient

Including higher corrections from modes 3, 4, 5, ... and solving the eigenvalue problem for the mixed mode Hamiltonian yields corrected energies \(\tilde{E}_1, \tilde{E}_2, \ldots\)
