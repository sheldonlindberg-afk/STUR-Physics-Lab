STUR-X 5D Negative Energy
Exotic Stress-Energy and Wormhole Bounds

Derivation Overview (STUR-X 5D Uplift)

We start from the usual 4D effective picture of exotic stress–energy near a wormhole throat and then promote it to a STUR-X 5D geometry: a Lorentzian 4D manifold plus an informational / sideways time axis χ,

M₄(-+++) ⊕ χ, coordinates (t, r, θ, φ, χ).

In 4D, microscopic forces (electromagnetic, gravitational, strong-like, and spin-torsion) act on a test probe at radius r:

F_EM(r) = k_e q² / r², F_grav(r) = − G m² / r²,
F_strong(r) = α_s ((1 − e^{−r/λ}) / r² + σ r e^{−r/ℓ_Q}),
F_spin(r) ≈ γ₀ e^{−r/ℓ_B} S_mag B₀.

A STUR radial modulator S₀(r) encodes curvature and modular structure:

S₀(r) = tanh(r / L₀) (1 − e^{−r / L₀}) [1 + 0.1 sin(2π r / L_mod)].

To pass to STUR-X 5D, we let the sideways time coordinate χ track how bound vs. unbound information flows through the throat. We introduce a χ-envelope (local coherence) and a χ-curvature penalty:

E_χ(χ) = exp[−(χ/χ₀)²], C_χ(χ) = 1 / (1 + (χ/χ_c)²),
S_X(r, χ) = S₀(r) · E_χ(χ) · C_χ(χ).

At fixed χ, the total radial and non-radial contributions become

F_rad⁽⁵ᴰ⁾(r, χ) = S_X(r, χ) [F_EM(r) + F_grav(r) + F_strong(r)],
F_nonrad(r) = F_spin(r),

and we build an effective 5D exotic energy density and radial pressure with controlled χ-dependent fluctuations:

ρ(r, χ) ≈ b² / [8π (r² + b²)²] + δρ(r, χ),
p_r(r, χ) ≈ − S_X(r, χ) α_s σ r e^{−r/ℓ_Q} / [4π r² V₀] + δp(r, χ),

with b the throat scale, V₀ an effective cell volume and χ-noise tuned so that fluctuations are strongest near the throat and near the χ-axis where topology can change.

The combination ρ + p_r still controls energy-condition violation. From it we compute at each (r, χ):

  • Local exotic entropy density s(r, χ) ∝ |ρ + p_r| / T_P
  • Entanglement entropy (holographic-like) S_ent(r, χ) ≈ − A(r) / (4 ℓ_P²) log[1 + |ρ + p_r| / ρ_P] / k_B
  • Bekenstein and holographic bounds using E ≈ ρ(r, χ) V₀ and A = 4π r²

To quantify how “STUR-X coherent” a configuration is, we define an X-coherence indicator

κ_X(r, χ) = S_X(r, χ)² / [1 + |ρ(r, χ) + p_r(r, χ)| / ρ_P],

so that large modulator and small energy-condition violation give high κ_X. We then average over χ to get 5D radial profiles,

⟨…⟩_χ = (1 / Δχ) ∫ dχ (…)  (discretized in the code).

Stability is probed by the sign of d/dr ⟨ρ + p_r⟩_χ; a positive gradient flags an instability. A topology flag is raised whenever ⟨ρ + p_r⟩_χ < 0 at a diagnostic radius. A simple traversal-time integral,

τ(r) ≈ ∫ dl / √(1 − b² / r(l)²),

is compared to external light travel time 2r/c to tag potential causality violations.

The Python engine below:

  • Samples r from near Planck length to atomic scales,
  • Samples χ across a sideways-time band,
  • Runs several noise realizations,
  • Averages all observables over χ and Monte-Carlo runs,
  • Generates diagnostic plots for forces, (ρ + p_r), entropies, bounds, and X-coherence,
  • Prints a detailed table plus a JSON blob ready for archiving.

Philosophically, STUR-X treats negative energy not as free energy, but as a bookkeeping of how information and curvature are traded between bound and unbound states along χ. Stable wormholes are then high-κ_X regions where those trades remain coherent across all five dimensions.

Python Simulation (STUR-X 5D, Jupyter/JupyterLite-safe)

#!/usr/bin/env python3
# ==================================================================
# STUR-X 5D Negative Energy – Exotic Stress-Energy and Wormhole Bounds
#   • 5D manifold: M4(-+++) ⊕ χ
#   • χ = sideways time / information axis
#   • Jupyter-safe: NumPy + Matplotlib + JSON only
# ==================================================================

import numpy as np
import matplotlib.pyplot as plt
import json

# ------------------ CONSTANTS (SI) ------------------------------
k_e   = 8.9875e9      # N·m^2/C^2
G     = 6.6743e-11    # N·m^2/kg^2
q     = 1.602e-19     # C (proton charge)
m     = 1.673e-27     # kg (proton mass)
alpha_s = 1e-26       # N·m^2 (effective strong-like)
sigma   = 1e50        # N/m (tuned confinement)
lambda_ = 1e-15       # m (strong range)
L_0     = 1e-35       # m (STUR modulation scale)
L_mod   = 1e-34       # m (modulation period)
V_0     = 1e-45       # m^3 (effective coarse-grained cell)
b       = 1e-15       # m (throat radius)
ell_Q   = 1e-35       # m (QEI cutoff)
hbar    = 1.055e-34   # J·s
c       = 3e8         # m/s
k_B     = 1.38e-23    # J/K
T_P     = 1.42e32     # K (Planck temperature)
ell_P   = 1.616e-35   # m (Planck length)
m_P     = 2.176e-8    # kg (Planck mass)
rho_P   = m_P * c**2 / ell_P**3  # ~1e97 J/m^3 (Planck energy density)
gamma_0 = 1e-20       # N·m (torque coefficient)
ell_B   = 1e-10       # m (spin decay scale)
B_0     = 1e-5        # T (background B-field)
S_mag   = hbar / 2.0  # spin magnitude

# STUR-X χ-dimension parameters
chi_0   = 1.0         # coherence width in χ (dimensionless)
chi_c   = 2.0         # curvature penalty scale in χ (dimensionless)
chi_max = 4.0         # χ-range: [-chi_max, chi_max]
N_chi   = 41          # number of χ samples

fluct_scale = hbar / c  # base fluctuation scale
num_runs    = 8         # number of Monte Carlo noise realizations

# ------------------ RADIAL / SIDEWAYS GRIDS --------------------
r_values   = np.logspace(-35, -10, num=20)
chi_values = np.linspace(-chi_max, chi_max, N_chi)

# ------------------ STUR & STUR-X MODULATORS -------------------
def S0(r):
    """Pure radial STUR modulator (4D)."""
    mod_flow = 1.0 + 0.1 * np.sin(2.0 * np.pi * r / L_mod)
    return mod_flow * np.tanh(r / L_0) * (1.0 - np.exp(-r / L_0))

def S_X(r, chi):
    """
    STUR-X 5D modulator:
      • S0(r): radial curvature / modular flow
      • exp(-(chi/chi0)^2): χ coherence envelope
      • 1 / (1 + (chi/chi_c)^2): χ curvature penalty
    """
    s0  = S0(r)
    env = np.exp(-(chi / chi_0)**2)
    curv_pen = 1.0 / (1.0 + (chi / chi_c)**2)
    return s0 * env * curv_pen

# ------------------ FORCE COMPONENTS ----------------------------
def F_EM(r):
    return k_e * q * q / r**2 if r > 0.0 else 0.0

def F_grav(r):
    return -G * m * m / r**2 if r > 0.0 else 0.0

def F_strong(r):
    if r <= 0.0:
        return 0.0
    linear_term = sigma * r * np.exp(-r / ell_Q)
    return alpha_s * ((1.0 - np.exp(-r / lambda_)) / r**2 + linear_term)

def F_spin(r):
    """Magnitude of an effective spin-torsion force (non-radial)."""
    return gamma_0 * np.exp(-r / ell_B) * S_mag * B_0

# 5D total forces (radial depends on χ via S_X)
def F_total_rad_5D(r, chi):
    return S_X(r, chi) * (F_EM(r) + F_grav(r) + F_strong(r))

def F_total_nonrad(r, chi):
    # Option: keep non-radial independent of χ or mildly modulated
    return F_spin(r) * (1.0 + 0.1 * np.tanh(chi / chi_c))

# ------------------ ENERGY DENSITY & PRESSURE -------------------
def rho(r, chi, fluct=True):
    """Effective 5D energy density with χ-sensitive fluctuations."""
    l = max(r, ell_P)
    base_rho = (b**2) / (8.0 * np.pi * (l**2 + b**2)**2)

    if fluct:
        # Noise stronger near throat and χ ~ 0
        denom = max(l**2 + 0.25 * (chi * ell_P)**2, 1.0e-70)
        noise_scale = fluct_scale / denom
        noise = np.random.normal(0.0, noise_scale)
        base_rho += noise

    return float(np.clip(base_rho, -rho_P, rho_P))

def p_r(r, chi, fluct=True):
    """Effective 5D radial pressure with controlled fluctuations."""
    if r <= 0.0:
        base_pr = 0.0
    else:
        linear_term = sigma * r * np.exp(-r / ell_Q)
        base_pr = -S_X(r, chi) * alpha_s * linear_term / (4.0 * np.pi * r**2 * V_0)

    if fluct and r > 0.0:
        denom = max(r**2 + 0.25 * (chi * ell_P)**2, 1.0e-70)
        noise_scale = fluct_scale / denom
        noise = np.random.normal(0.0, noise_scale)
        base_pr += noise

    return float(np.clip(base_pr, -rho_P, rho_P))

# ------------------ ENTROPY AND BOUNDS --------------------------
def s_exotic(rho_val, p_r_val):
    """Exotic entropy density (positive) in k_B units times V0."""
    val = abs(rho_val + p_r_val) / T_P  # J/m^3/K
    return float(val * V_0 / k_B)

def S_ent(r, rho_plus_pr):
    """Approximate holographic entanglement entropy in k_B units."""
    if rho_plus_pr == 0.0:
        return 0.0
    A = 4.0 * np.pi * r**2
    ratio = abs(rho_plus_pr) / rho_P
    return float(-(A / (4.0 * ell_P**2)) * np.log(1.0 + ratio) / k_B)

def S_bekenstein(r, rho_val):
    """Bekenstein entropy bound in k_B units."""
    E = rho_val * V_0  # J (energy in volume V0)
    return float((2.0 * np.pi * r * E) / (hbar * c * k_B))

def S_holographic(r):
    """Holographic entropy bound in k_B units."""
    A = 4.0 * np.pi * r**2
    return float(A / (4.0 * ell_P**2 * k_B))

# ------------------ X-COHERENCE METRIC --------------------------
def kappa_X_metric(SX_val, rho_val, p_r_val):
    """
    STUR-X coherence indicator:
      κ_X = S_X^2 / (1 + |ρ + p_r| / ρ_P)
    """
    denom = 1.0 + abs(rho_val + p_r_val) / rho_P
    return float((SX_val * SX_val) / denom)

# ------------------ STABILITY & TOPOLOGY ------------------------
def stability(r_vals, rho_plus_pr_vals):
    """Check if d(ρ+pr)/dr ever > 0 (instability)."""
    d_dr = np.diff(rho_plus_pr_vals) / np.diff(r_vals)
    return "Unstable" if np.any(d_dr > 0.0) else "Stable"

def topology_change(rho_plus_pr):
    """Flag potential topology change if ρ + pr < 0."""
    return "Possible topology change" if rho_plus_pr < 0.0 else "No change"

# ------------------ TRAVERSAL TIME (4D GEOMETRIC PROXY) --------
def traversal_time(r):
    """
    Compare approximate proper traversal time through a throat
    against external light travel time 2r/c.
    """
    l = np.linspace(-10.0 * r, 10.0 * r, 200)
    r_l = np.sqrt(l**2 + b**2)
    inside = 1.0 - (b**2 / (r_l**2 + 1.0e-40))
    inside_clipped = np.clip(inside, 1.0e-12, 1.0)
    integrand = 1.0 / np.sqrt(inside_clipped)
    tau = np.trapz(integrand, l)  # dimensionless factor
    ext_time = 2.0 * r / c
    status = "Causality preserved" if ext_time > tau else "Violation risk"
    return float(tau), float(ext_time), status

# ------------------ MONTE CARLO AVERAGING (OVER χ & RUNS) ------
avg_data = {
    "r": r_values,
    "S": [],
    "F_rad": [],
    "F_nonrad": [],
    "rho": [],
    "p_r": [],
    "rho_pr": [],
    "S_exo": [],
    "S_ent": [],
    "S_bek": [],
    "S_hol": [],
    "kappa_X_mean": [],
    "kappa_X_max": []
}

for run in range(num_runs):
    for i, r in enumerate(r_values):

        # Ensure per-radius containers exist
        if len(avg_data["S"]) <= i:
            for key in avg_data:
                if key != "r":
                    avg_data[key].append([])

        S_list      = []
        F_rad_list  = []
        F_non_list  = []
        rho_list    = []
        pr_list     = []
        rho_pr_list = []
        S_exo_list  = []
        S_ent_list  = []
        S_bek_list  = []
        S_hol_list  = []
        kappa_list  = []

        for chi in chi_values:
            sx     = S_X(r, chi)
            f_rad  = F_total_rad_5D(r, chi)
            f_non  = F_total_nonrad(r, chi)
            rho_v  = rho(r, chi,  fluct=True)
            pr_v   = p_r(r, chi,  fluct=True)
            rho_pr = rho_v + pr_v

            s_exo  = s_exotic(rho_v, pr_v)
            s_ent  = S_ent(r, rho_pr)
            s_bek  = S_bekenstein(r, rho_v)
            s_hol  = S_holographic(r)
            kappa  = kappa_X_metric(sx, rho_v, pr_v)

            S_list.append(sx)
            F_rad_list.append(f_rad)
            F_non_list.append(f_non)
            rho_list.append(rho_v)
            pr_list.append(pr_v)
            rho_pr_list.append(rho_pr)
            S_exo_list.append(s_exo)
            S_ent_list.append(s_ent)
            S_bek_list.append(s_bek)
            S_hol_list.append(s_hol)
            kappa_list.append(kappa)

        # χ-averages for this run and radius
        avg_data["S"][i].append(float(np.mean(S_list)))
        avg_data["F_rad"][i].append(float(np.mean(F_rad_list)))
        avg_data["F_nonrad"][i].append(float(np.mean(F_non_list)))
        avg_data["rho"][i].append(float(np.mean(rho_list)))
        avg_data["p_r"][i].append(float(np.mean(pr_list)))
        avg_data["rho_pr"][i].append(float(np.mean(rho_pr_list)))
        avg_data["S_exo"][i].append(float(np.mean(S_exo_list)))
        avg_data["S_ent"][i].append(float(np.mean(S_ent_list)))
        avg_data["S_bek"][i].append(float(np.mean(S_bek_list)))
        avg_data["S_hol"][i].append(float(np.mean(S_hol_list)))
        avg_data["kappa_X_mean"][i].append(float(np.mean(kappa_list)))
        avg_data["kappa_X_max"][i].append(float(np.max(kappa_list)))

# Average over runs
for key in avg_data:
    if key != "r":
        avg_data[key] = [float(np.mean(vals)) for vals in avg_data[key]]

# ------------------ TABLE OUTPUT --------------------------------
print("| r (m)     | S_X(avg)  | F_rad (N) | F_nonrad (N) | rho (J/m^3) | p_r (J/m^3) | rho+pr (J/m^3) | S_exo (k_B) | S_ent (k_B) | S_bek (k_B) | S_hol (k_B) | kappa_X(avg) |")
print("|-----------|-----------|-----------|--------------|-------------|-------------|----------------|------------|------------|------------|------------|-------------|")
for i, r in enumerate(avg_data["r"]):
    print(
        "| {r:.2e} | {S:.2e} | {Fr:.2e} | {Fn:.2e} | {rh:.2e} | {pr:.2e} | {rpr:.2e} | {SE:.2e} | {Sent:.2e} | {Sbk:.2e} | {Sh:.2e} | {kX:.2e} |".format(
            r   = r,
            S   = avg_data["S"][i],
            Fr  = avg_data["F_rad"][i],
            Fn  = avg_data["F_nonrad"][i],
            rh  = avg_data["rho"][i],
            pr  = avg_data["p_r"][i],
            rpr = avg_data["rho_pr"][i],
            SE  = avg_data["S_exo"][i],
            Sent= avg_data["S_ent"][i],
            Sbk = avg_data["S_bek"][i],
            Sh  = avg_data["S_hol"][i],
            kX  = avg_data["kappa_X_mean"][i]
        )
    )

# ------------------ GLOBAL DIAGNOSTICS -------------------------
stab = stability(r_values, avg_data["rho_pr"])
print("\nOverall Stability (χ-averaged): {}".format(stab))

diag_points = []
for r_ex in [r_values[0], r_values[len(r_values)//2], r_values[-1]]:
    idx = int(np.argmin(np.abs(r_values - r_ex)))
    rho_pr_ex = avg_data["rho_pr"][idx]
    topo      = topology_change(rho_pr_ex)
    tau, ext_t, caus = traversal_time(r_ex)
    diag_points.append({
        "r_m": float(r_ex),
        "rho_plus_p_r_J_per_m3": float(rho_pr_ex),
        "topology_flag": topo,
        "tau_dimless": tau,
        "external_time_s": ext_t,
        "causality": caus,
        "kappa_X_mean": float(avg_data["kappa_X_mean"][idx]),
        "kappa_X_max": float(avg_data["kappa_X_max"][idx])
    })
    print(
        "At r={:.2e} m: rho+pr={:.2e}, {}, tau~{:.2e}, t_ext~{:.2e} s ({}) | kappa_X(avg)~{:.2e}, kappa_X(max)~{:.2e}".format(
            r_ex, rho_pr_ex, topo, tau, ext_t, caus,
            avg_data["kappa_X_mean"][idx],
            avg_data["kappa_X_max"][idx]
        )
    )
