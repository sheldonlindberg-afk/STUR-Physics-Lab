STUR Field Equation & 3-Layer Seed Architecture

From 5D STUR Physics to the Seed Simulator v1.0

The STUR Seed Simulator is not an AGI system and makes no claims about consciousness, understanding, or agency. It is a fully open, 3D, multi-layer, resistance-based dynamical system that implements a discretized version of the STUR resistance field with memory feedback and goal forcing.

1. STUR Resistance Field on a 5D Manifold

In STUR, the unified resistance field \(R(x,t,X)\) lives on a 5D manifold: three spatial coordinates, one time coordinate, and one feedback dimension \(X\). The core evolution law is

\[ \frac{\partial R}{\partial t} \;=\; \nabla \cdot (D \nabla R) \;-\; \nabla R \cdot \Omega \;+\; \chi \,\frac{\partial R}{\partial X} \;+\; S \]
(1) STUR resistance evolution

The hidden feedback dimension \(X\) carries memory, coherence, and deterministic information that appears as randomness when projected down into 4D spacetime. In this seed we use the linear closure

\[ \frac{\partial R}{\partial X} \;=\; \frac{R - R_{\text{bg}}}{L_X} \]
(2) X-coupling closure

Taken together, (1)–(2) define a resistance manifold that:

  • diffuses structure \(\nabla\cdot(D\nabla R)\),
  • advects along a drift vector \(\Omega\),
  • couples to hidden feedback via \(\chi \partial R/\partial X\),
  • and is driven by sources \(S\) (inputs, noise, goals).

2. Layered Manifold and Memory Fields

SeedSim v1.0 uses three coupled layers, each with a resistance field and a memory field:

\[ (R_1, X_1) \;\text{: sensory layer} \] \[ (R_2, X_2) \;\text{: association / goal layer} \] \[ (R_3, X_3) \;\text{: stabilizer / integrator layer} \]

The memory fields \(X_\ell\) (\(\ell = 1,2,3\)) are leaky, driven by deviations of the local resistance from its mean:

\[ \frac{\partial X_\ell}{\partial t} = -\gamma_{X,\ell}\, X_\ell + \chi_{X,\ell}\,\bigl(R_\ell - \langle R_\ell \rangle\bigr), \quad \ell \in \{1,2,3\}. \]
(3) Memory dynamics per layer

This implements a basic form of “what stays different from the mean gets remembered.”

3. Nonlinear Potential and Local Feedback

To prevent trivial collapse and to create filamentary structure, each layer has a local cubic potential around a background state \(R_{\text{bg}}\):

\[ V_\ell(R_\ell) = \frac{\lambda_{V,\ell}}{4}\,(R_\ell - R_{\text{bg}})^4, \quad \Rightarrow \quad -\frac{\partial V_\ell}{\partial R_\ell} = -\lambda_{V,\ell}(R_\ell - R_{\text{bg}})^3. \]
(4) Local double-well–like nonlinearity

The hidden-dimension feedback is implemented as

\[ \chi_\ell\,\frac{\partial R_\ell}{\partial X} \;\approx\; \chi_\ell^{\text{eff}}\,\frac{R_\ell - R_{\text{bg}}}{L_X}, \quad \chi_\ell^{\text{eff}} = \chi_\ell\bigl(1+\alpha_{\chi,\ell}\tanh X_\ell\bigr), \]
(5) X-feedback with memory-modulated gain

so that regions with strong memory \(X_\ell\) amplify or suppress the feedback term.

4. Discrete Lattice and Update Rule

We simulate on a periodic cubic lattice of spacing \(dx\) with explicit Euler time-stepping of size \(dt\). The Laplacian and gradient are implemented as:

\[ \nabla^2 R(i,j,k) = \frac{1}{dx^2} \Bigl[ R_{i+1,j,k} + R_{i-1,j,k} + R_{i,j+1,k} + R_{i,j-1,k} + R_{i,j,k+1} + R_{i,j,k-1} - 6R_{i,j,k} \Bigr], \] \[ \nabla R \approx \Bigl( \frac{R_{i+1,j,k} - R_{i-1,j,k}}{2dx}, \frac{R_{i,j+1,k} - R_{i,j-1,k}}{2dx}, \frac{R_{i,j,k+1} - R_{i,j,k-1}}{2dx} \Bigr). \]
(6) Periodic finite differences

The effective diffusion and X-feedback gains are modulated by memory using a local gain field \(g_\ell = \tanh X_\ell\):

\[ D_\ell^{\text{eff}} = D_\ell\bigl(1 + \alpha_{D,\ell}\,g_\ell\bigr), \quad \chi_\ell^{\text{eff}} = \chi_\ell\bigl(1 + \alpha_{\chi,\ell}\,g_\ell\bigr). \]
(7) Memory-modulated diffusion & feedback

A generic layer update (before global normalization) is then:

\[ R_\ell^{n+1} = R_\ell^{n} + dt\, \Bigl[ D_\ell^{\text{eff}} \nabla^2 R_\ell^n - \nabla R_\ell^n \cdot \Omega_\ell + \chi_\ell^{\text{eff}} \frac{R_\ell^n - R_{\text{bg}}}{L_X} + k_{\text{couple},\ell} X_\ell^n - \lambda_{V,\ell}(R_\ell^n - R_{\text{bg}})^3 + S_\ell^n \Bigr]. \]
(8) Discrete resistance update per layer

The memory field uses explicit Euler on (3):

\[ X_\ell^{n+1} = X_\ell^{n} + dt\, \Bigl( -\gamma_{X,\ell} X_\ell^n + \chi_{X,\ell}(R_\ell^n - \langle R_\ell^n \rangle) \Bigr). \]
(9) Discrete memory update

5. Cross-Layer Coupling and Goal Forcing

The source term \(S_\ell\) includes homeostatic drive towards \(R_{\text{bg}}\), noise, sensory inputs, symbolic masks, and inter-layer couplings. For example, on the association layer:

\[ S_2 = s_2(R_{\text{bg}} - R_2) + \eta_2 + c_{12}(R_1 - R_2) + c_{32}(R_3 - R_2) + G(x,y,z)\,\bigl(R_{\text{bg}} - R_2\bigr), \]
(10) Association source term with goal mask \(G\)

where the goal mask \(G\) is a Gaussian bump in a chosen region of the volume, and the symbolic inputs are oscillatory Gaussian blobs in the sensory layer that alternate via a phase \(\sin(\omega_{\text{sym}} t)\).

6. Global Energy Normalization

To keep the manifold numerically stable and independent of the absolute scale of forcing, SeedSim v1.0 enforces a global RMS constraint over all three layers:

\[ \mathrm{RMS}_{\text{all}}^n = \sqrt{\bigl\langle R_1^{n\,2} + R_2^{n\,2} + R_3^{n\,2} \bigr\rangle}, \qquad \alpha^n = \frac{R_{\text{target}}}{\mathrm{RMS}_{\text{all}}^n + \varepsilon}. \] \[ R_\ell^{n+1} \leftarrow \alpha^n\,R_\ell^{n+1}, \quad \ell=1,2,3. \]
(11) Global RMS normalization

This is the “S3” stabilization choice: it keeps the total resistance energy near a fixed target while still allowing rich internal structure and alignment dynamics to emerge.

Empirical Behavior of v1.0

Three-Layer Dynamics and Measured Outputs

With the default parameters on a \(32^3\) grid, \(dt=0.005\), 2000 steps (final time \(t=10\)), the SeedSim v1.0 shows stable, interpretable, goal-responsive behavior.

Layer Roles

  • Sensory layer \((R_1,X_1)\): receives static, dynamic, and symbolic Gaussian inputs.
  • Association layer \((R_2,X_2)\): receives input from \(R_1\) and a static goal mask.
  • Stabilizer layer \((R_3,X_3)\): integrates activity from \(R_1\) and \(R_2\) and smooths it.

Key Quantities Tracked

During a run, the simulator records:

  • Mean and standard deviation of each \(R_\ell\) and \(X_\ell\)
  • Curvature \(\langle |\nabla R_\ell|^2 \rangle\) per layer
  • Coherence \(\mathrm{corr}(R_\ell, X_\ell)\) per layer
  • Alignments of \(R_1\) with static, dynamic, and symbolic input masks
  • Alignments of \(R_2\) and \(R_3\) with the goal mask
  • Global RMS of all \(R\)-fields

Reading the Behavior (No Hype)

  • The global RMS is held near 1.0, confirming stable energy normalization.
  • Coherences near 1.0 mean memory fields track the resistance fields closely.
  • High static alignment and low dynamic alignment show that persistent inputs are reinforced, while purely oscillatory inputs are partially ignored.
  • Goal alignment on layers 2 and 3 indicates that the association and stabilizer layers conform to the goal mask.

The system is therefore best described as a goal-biased, memory-modulated resistance manifold that forms stable attractors under the STUR feedback rules, not as an intelligent agent.
