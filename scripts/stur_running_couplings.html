1. Beta Functions in STUR TOE

1.1 Definition

The beta function describes how a coupling g evolves with energy scale μ:

\[\beta(g) \equiv \mu \frac{dg}{d\mu} = \frac{dg}{d\ln\mu}\]
(1.1)

1.2 One-Loop Beta Functions

For a non-Abelian gauge theory with gauge group G:

\[\boxed{\beta(g) = -\frac{g^3}{16\pi^2}\left[\frac{11}{3}C_2(G) - \frac{4}{3}\sum_f T(r_f) - \frac{1}{6}\sum_s T(r_s)\right]}\]
(1.2) — One-loop beta function

where:

  • C2(G) = quadratic Casimir of adjoint (N for SU(N))
  • T(rf) = Dynkin index of fermion representation
  • T(rs) = Dynkin index of scalar representation
