1. Beta Functions: Definition and Derivation

1.1 The Renormalization Group Equation

The beta function describes the energy-scale dependence of a coupling constant g. For a gauge coupling:

\[\Quant{\beta(g)} \equiv \mu \frac{dg}{d\mu} = \frac{dg}{d\ln\mu}\]
(RC.1.1) — Beta function definition

This governs how the coupling strength changes as we probe physics at different energy scales mu.

1.2 One-Loop Beta Function for Non-Abelian Gauge Theory

For a non-Abelian gauge theory with gauge group G, the one-loop beta function is:

\[\boxed{\beta(g) = -\frac{g^3}{16\pi^2}\left[\frac{11}{3}C_2(G) - \frac{4}{3}\sum_f T(r_f) - \frac{1}{6}\sum_s T(r_s)\right]}\]
(RC.1.2) — One-loop gauge beta function

where the group theory factors are:

  • C_2(G) = quadratic Casimir of the adjoint representation (= N for SU(N))
  • T(r_f) = Dynkin index of each Weyl fermion representation (= 1/2 for fundamental)
  • T(r_s) = Dynkin index of each complex scalar representation
Derivation: Origin of the Beta Function Terms Advanced

The three contributions to the beta function arise from different sources:

The gauge boson contribution dominates for small matter content, giving asymptotic freedom.
