E.4 Tabletop Sagnac Loops: Area Enhancement

Sagnac interferometers probe a different regime than linear-path experiments. For closed loops, the XCRM holonomy depends on enclosed area, not path difference.

Loop Visibility Formula

\[\boxed{\Matt{V_{\rm loop}} = V_0 \exp\!\left(-\frac{\Matt{A_{\rm loop}}^2}{\Matt{A_{\rm coh}}^2}\right)}\]
(E.5) — Loop visibility (area scaling)

where the coherence area is:

\[\Matt{A_{\rm coh}} = \frac{\XCRM{L_X}^2}{\Diff{\sigma_R}} = \Matt{\ell_{\rm coh}} \cdot \XCRM{L_X}\]
(E.6) — Coherence area

Example: 1 m² Sagnac Loop

ParameterValue

Key Advantage: Zero Path Difference

Unlike linear interferometers, Sagnac loops have \(\Matt{\Delta L} = 0\) (both arms traverse the same path). This eliminates standard decoherence mechanisms that depend on path-length difference. Any visibility decay in a perfect Sagnac loop must come from area-dependent effects like STUR.

Area Enhancement Factor

Comparing loop and linear geometries at the same total path length \(L\):

\[\frac{\langle \Quant{\Phi_R}^2 \rangle_{\rm loop}}{\langle \Quant{\Phi_R}^2 \rangle_{\rm linear}} = \frac{A/\XCRM{L_X}^2}{(\Delta L/\Matt{\ell_{\rm coh}})^2} \sim \frac{L^2}{4\XCRM{L_X}^2}\]
(E.7) — Loop enhancement factor

For \(L = 4\) m and \(\XCRM{L_X} = 1\) μm, the enhancement is \(\sim 10^{12}\) — enabling macroscopic observability even with microscopic \(\XCRM{L_X}\).
