STUR Feynman Rules

Complete Diagrammatic Perturbation Theory

Propagators, vertices, and loop rules from the Master Action on Z₃ helix · v2.5

Overview

These Feynman rules are derived from the STUR Master Action (from XCRM) via the path integral. They enable systematic calculation of scattering amplitudes and loop corrections.

Key Features
  • 5D propagators with KK mode summation
  • Holonomy-regulated UV behavior
  • Standard Model vertices at low energy
  • XCRM vertices for R-field interactions

1. Propagators

1.1 Scalar (R-Field) Propagator

The resistance field R propagator in momentum space:

\[\boxed{\feynmandiagram[inline=(a.base), horizontal=a to b]{a -- [scalar] b}; = \frac{i}{p^2 - m_R^2 + i\varepsilon} \cdot W_{\rm hol}(p)}\]
(1.1) — R-field propagator

where the holonomy weight factor is:

\[W_{\rm hol}(p) = e^{-\beta \Omega(p)} = e^{-\beta |p| L_X}\]
(1.2)

This provides automatic UV regulation without introducing a hard cutoff.

1.2 Fermion Propagator

For 4D fermions after KK reduction:

\[\boxed{\feynmandiagram[inline=(a.base), horizontal=a to b]{a -- [fermion] b}; = \frac{i(\slashed{p} + m)}{p^2 - m^2 + i\varepsilon}}\]
(1.3) — Fermion propagator

The fermion mass m includes contributions from both Higgs VEV and wavefunction localization.

1.3 Gauge Boson Propagator

In Feynman gauge (ξ = 1):

\[\boxed{\feynmandiagram[inline=(a.base), horizontal=a to b]{a -- [photon] b}; = \frac{-i g_{\mu\nu}}{k^2 + i\varepsilon}}\]
(1.4) — Gauge boson propagator (massless)

For massive gauge bosons (W, Z):

\[\frac{-i(g_{\mu\nu} - k_\mu k_\nu/M^2)}{k^2 - M^2 + i\varepsilon}\]
(1.5)

1.4 Graviton Propagator

In de Donder gauge:

\[\feynmandiagram[inline=(a.base), horizontal=a to b]{a -- [gluon] b}; = \frac{i P_{\mu\nu,\rho\sigma}}{k^2 + i\varepsilon}\]
(1.6)

where Pμν,ρσ = ½(ημρηνσ + ημσηνρ - ημνηρσ).

1.5 KK Mode Propagators

For the n-th Kaluza-Klein mode:

\[\boxed{G_n(p) = \frac{i}{p^2 - m_n^2 + i\varepsilon}, \quad m_n = \frac{n}{L_X}}\]
(1.7) — KK mode propagator

Full 5D propagator sums over all modes:

\[G_{\rm 5D}(p, p_5) = \sum_{n=-\infty}^{\infty} \frac{i}{p^2 - (n/L_X)^2 + i\varepsilon} \cdot \delta(p_5 - n/L_X)\]
(1.8)

2. Interaction Vertices

2.1 Yukawa Vertex (R-ψ-ψ̄)

The fundamental STUR matter coupling:

\[\boxed{\feynmandiagram[inline=(v.base), horizontal=a to v to b]{a -- [fermion] v -- [fermion] b, v -- [scalar] c}; = -iy}\]
(2.1) — Yukawa vertex

This generates fermion masses and quantum phases from R-field.

2.2 Gauge-Fermion Vertex

\[\boxed{\feynmandiagram[inline=(v.base), horizontal=a to v to b]{a -- [fermion] v -- [fermion] b, v -- [photon] c}; = -ig\gamma^\mu T^a}\]
(2.2) — Gauge-fermion vertex

where Ta are the gauge group generators in the appropriate representation.

2.3 Triple Gauge Vertex

For non-Abelian gauge fields:

\[\feynmandiagram[inline=(v.base)]{a -- [photon] v, b -- [photon] v, c -- [photon] v}; = gf^{abc}\left[g^{\mu\nu}(k_1 - k_2)^\rho + \text{cyclic}\right]\]
(2.3)

2.4 Quartic Gauge Vertex

\[\feynmandiagram[inline=(v.base)]{a -- [photon] v, b -- [photon] v, c -- [photon] v, d -- [photon] v}; = -ig^2\left[f^{abe}f^{cde}(g^{\mu\rho}g^{\nu\sigma} - g^{\mu\sigma}g^{\nu\rho}) + \text{perms}\right]\]
(2.4)

2.5 XCRM Vertices

The XCRM coupling \(\XCRM{\chi}(\Diff{R_1}\partial_X\Diff{R_2} - \Diff{R_2}\partial_X\Diff{R_1})\) generates unique vertices:

\[\boxed{\XCRM{V_{\rm XCRM}} = i\XCRM{\chi}\left(p_X^{(2)} - p_X^{(1)}\right)}\]
(2.5a) — XCRM vertex: R1-R2 coupling

where \(p_X^{(i)}\) is the fifth-momentum component of leg \(i\). In polar form \(\Diff{R} = \rho e^{i\phi}\):

\[\boxed{\XCRM{V_{\rm XCRM}^{\rm polar}} = i\XCRM{\chi}\rho^2 \cdot p_X^{(\phi)}}\]
(2.5b) — XCRM vertex in polar representation

2.6 XCRM-Gravity Vertex

The \(\Tor{\alpha}|\Diff{R}|\mathbb{T}\) coupling gives the R-gravity-torsion interaction:

\[\boxed{\Tor{V_{R\mathbb{T}}} = i\Tor{\alpha} \cdot \Tor{T_{\mu\nu\rho\sigma}}}\]
(2.6) — R-gravity-torsion vertex

where \(\Tor{T_{\mu\nu\rho\sigma}}\) is the torsion tensor structure.

2.7 XCRM Z3 Phase Vertex

At Z3 fixed points, vertices carry phase factors:

\[\boxed{\XCRM{V_n^{(Z_3)}} = \XCRM{V_n} \times \exp\left(i\frac{2\pi n}{3}\right), \quad n \in \{0, 1, 2\}}\]
(2.7) — Z3 phase-dressed vertex
XCRM Vertices Are Unique

The XCRM vertices are the only first-derivative couplings for the R-doublet. They measure winding rate \(\partial_X\phi\) in field space, coupling matter to the Z3 helix structure.

2.8 Higgs Vertices

Since H = A5, Higgs interactions come from gauge kinetic terms:

\[\feynmandiagram[inline=(v.base)]{a -- [scalar] v, b -- [photon] v, c -- [photon] v}; = ig^2 v\, g^{\mu\nu}\]
(2.8) — HWW vertex
\[\feynmandiagram[inline=(v.base)]{a -- [scalar] v, b -- [fermion] v -- [fermion] c}; = -\frac{im_f}{v}\]
(2.9) — Hff̄ vertex

4. Loop Integration Rules

4.1 Loop Momentum Integration

For each internal momentum not fixed by conservation:

\[\boxed{\int \frac{d^4k}{(2\pi)^4} \cdot W_{\rm hol}(k)}\]
(4.1) — Loop integration with holonomy weight

4.2 Fermion Loop Factor

\[\text{Closed fermion loop}: \quad (-1) \times \text{Tr}[\cdots]\]
(4.2)

4.3 Symmetry Factor

\[\text{Symmetry factor}: \quad \frac{1}{S}\]
(4.3)

where S is the order of the automorphism group of the diagram.

4.4 KK Sum

For each internal line in the 5D theory:

\[\boxed{\sum_{n=-\infty}^{\infty} \text{(with } p_5 = n/L_X \text{)}}\]
(4.4) — KK mode summation

4.5 UV Finiteness

The holonomy weight Whol(k) ensures all loop integrals converge:

\[\int d^4k\, \frac{e^{-\beta|k|L_X}}{(k^2)^n} < \infty \quad \text{for all } n \geq 0\]
(4.5)
No Regularization Needed

Unlike standard QFT, STUR loop integrals are finite without dimensional regularization or other artificial regulators. The holonomy weight provides a natural physical cutoff.

4.6 XCRM Loop Contributions

The XCRM vertex contributes to loop diagrams with an additional phase factor:

\[\boxed{\XCRM{\Sigma_{\rm XCRM}(p)} = \frac{\XCRM{\chi}^2}{\XCRM{L_X}} \sum_n \XCRM{W_n^2} \int \frac{d^4k}{(2\pi)^4} \frac{k_X^2}{(k^2 + m_n^2)^2}}\]
(4.6) — XCRM self-energy contribution

where the holonomy weights \(\XCRM{W_n} = |\sin(\pi(n + 1/3)/3)|\) regulate the KK sum.

4.7 Z3 Phase Averaging

In loop diagrams, sum over Z3 phases at each internal vertex:

\[\boxed{\sum_{g=0}^{2} \exp\left(i\frac{2\pi g}{3}\right) = 0 \quad \text{(Z}_3 \text{ phase cancellation)}}\]
(4.7) — Z3 phase averaging rule

This cancellation is responsible for anomaly cancellation and generation structure.

5. Example Calculations

5.1 Electron Self-Energy

One-loop correction to electron propagator:

\[\Sigma(p) = -e^2 \int \frac{d^4k}{(2\pi)^4} \frac{\gamma^\mu(\slashed{p} - \slashed{k} + m)\gamma_\mu}{[(p-k)^2 - m^2][k^2]} W_{\rm hol}(k)\]
(5.1)

5.2 Vacuum Polarization

\[\Pi^{\mu\nu}(q) = -e^2 \int \frac{d^4k}{(2\pi)^4} \frac{\text{Tr}[\gamma^\mu(\slashed{k}+m)\gamma^\nu(\slashed{k}-\slashed{q}+m)]}{[k^2-m^2][(k-q)^2-m^2]} W_{\rm hol}(k)\]
(5.2)

5.3 R-Field Self-Energy

From XCRM and Yukawa loops:

\[\Pi_R(p) = -y^2 \int \frac{d^4k}{(2\pi)^4} \frac{\text{Tr}[(\slashed{k}+m)(\slashed{k}-\slashed{p}+m)]}{[k^2-m^2][(k-p)^2-m^2]} W_{\rm hol}(k)\]
(5.3)

5.4 Finite Results

With holonomy regulation, these evaluate to:

\[\Sigma(p) = \frac{\alpha}{4\pi} m \left[\ln\frac{M_{\rm KK}^2}{m^2} - \frac{3}{2}\right] + O(p^2/M_{\rm KK}^2)\]
(5.4)

where MKK = 1/LX is the KK scale.

6. Renormalization

6.1 Counterterms

Even though loops are finite, we still define renormalized quantities:

\[\begin{aligned} \psi_{\rm bare} &= Z_\psi^{1/2} \psi_{\rm ren} \\ m_{\rm bare} &= Z_m m_{\rm ren} \\ e_{\rm bare} &= Z_e e_{\rm ren} \end{aligned}\]
(6.1)

6.2 Beta Functions

The STUR beta functions (from Running Couplings):

\[\boxed{\beta_g = \mu\frac{dg}{d\mu} = -\frac{g^3}{16\pi^2}\left(\frac{11}{3}C_A - \frac{4}{3}n_f T_F\right)}\]
(6.2) — Gauge coupling beta function

6.3 Running Masses

\[\gamma_m = \mu\frac{d\ln m}{d\mu} = -\frac{3\alpha}{4\pi}\]
(6.3)
