STUR Cosmology – Resistance-Origin Big Bang

Mechanism (No Singularity, No Prediction)

In STUR, the Big Bang is not an extrapolated singularity, explosion, or probabilistic jump. The universe is defined from the start as a continuous resistance field \(R\) on a Lorentzian manifold. What we label the “Big Bang” is the first global transition where resistance gradients become dynamically active and causal structure opens.

In the homogeneous limit \(R = R(t)\), the resistance field carries a finite energy density

\[ \rho_R = \tfrac12 \dot R^2 + V(R), \qquad V(R)=\tfrac12 m^2 (R-R_{\mathrm{bg}})^2, \]

and is subject to a saturation constraint arising from the hidden X–coupling of the STUR manifold. This imposes a finite resistance capacity \(\rho_c\), encoded by the effective density

\[ \rho_{\mathrm{eff}} = \rho_R\!\left(1-\frac{\rho_R}{\rho_c}\right). \]

When \(\rho_R \to \rho_c\), the effective density vanishes, forcing the Hubble rate to zero and producing a smooth causal turnaround. There is no singularity and no imposed bounce: expansion emerges because resistance must relax toward its background everywhere at once.

Time, curvature, and matter content appear together as consequences of this relaxation. The CMB, horizons, and structure formation follow as frozen resistance imprints, not as tuned initial conditions.

#!/usr/bin/env python3
# ===============================================================
# STUR Bounce Toy Model v1.0 — Homogeneous Resistance Cosmology
#   (Peer-review-defensible minimal mechanism, with plots + JSON)
# ===============================================================
"""
What this is (toy model, but defensible):
----------------------------------------
This is a *minimal* cosmological model built to reflect the STUR premise:

  1) The fundamental dynamical object is a continuous resistance field R on a
     Lorentzian manifold. In the homogeneous/isotropic limit, R = R(t).
  2) "Big Bang talk" is replaced by a *causal field mechanism*: global relaxation
     and saturation dynamics of R, not a singularity or probabilistic jump.
  3) Geometry is not prescribed as an initial-condition miracle. Instead we use
     a consistent closure: an FRW scale factor a(t) coupled to an effective
     resistance-energy density ρ_R.

Core assumptions (explicit, so reviewers can attack them cleanly):
------------------------------------------------------------------
A. Metric ansatz (standard): FRW with scale factor a(t), H = a_dot/a.
   This is not "assuming expansion"; it is the minimal symmetry reduction for
   a homogeneous universe. The dynamics (H(t)) comes from the field equation.

B. Resistance-field effective energy:
      ρ_R = 1/2 * R_dot^2 + V(R)
   with a simple quadratic potential around R_bg:
      V(R) = 1/2 * m^2 * (R - R_bg)^2
   This is a standard effective-field-energy construction. "m" is an effective
   stiffness/relaxation curvature scale.

C. STUR X-coupled saturation (the bounce mechanism):
   Instead of allowing unbounded energy density (which would drive singular
   behavior), we encode a saturation/closure that is natural in STUR because
   X-coupling imposes finite capacity of the resistance manifold:

      ρ_eff = ρ_R * (1 - ρ_R/ρ_c)

   where ρ_c is a critical resistance-energy density set by the XCRM capacity.
   When ρ_R → ρ_c, ρ_eff → 0, forcing H → 0 and triggering a bounce (turnaround).

   This is mathematically identical to a common "effective bounce" correction,
   but the interpretation is STUR: finite resistance capacity via X-coupling,
   not a quantum postulate. The toy model is intentionally transparent.

D. Dynamics of R(t):
   We use the standard covariant homogeneous scalar equation with Hubble
   friction (this is required by energy-momentum conservation in FRW):

      R_ddot + 3 H R_dot + dV/dR = 0

   Here it is not "a scalar inflaton"; it is the homogeneous mode of the STUR
   resistance field.

E. Friedmann closure:
      H^2 = (1/3) * ρ_eff
   sign(H) chosen by whether the universe is contracting or expanding.

What this model can (and cannot) claim:
---------------------------------------
- It *does* provide a clean physical mechanism for a non-singular origin:
  a causal saturation + relaxation of a single field.
- It *does not* claim to be a full STUR 5D PDE or to fit all cosmological data.
  It is the smallest defensible bridge from STUR language to testable dynamics.
- Extensions for reviewers: add radiation/matter fluids, perturbations,
  and compute CMB/structure observables (not done here).

Outputs:
--------
- a(t), H(t), ρ_R(t), and key bounce diagnostics.
- JSON summary for reproducibility.
"""

import json
import numpy as np
import matplotlib.pyplot as plt
from dataclasses import dataclass
from typing import Dict, Tuple

# --- SciPy is great if available; fallback included so this runs on JupyterLite. ---
try:
    from scipy.integrate import solve_ivp  # type: ignore
    _HAVE_SCIPY = True
except Exception:
    solve_ivp = None
    _HAVE_SCIPY = False

plt.style.use("dark_background")

# ===============================================================
# Parameters
# ===============================================================

@dataclass(frozen=True)
class Params:
    # Background resistance level
    R_bg: float = 0.0

    # Effective stiffness scale for the resistance potential
    m: float = 0.45

    # Critical resistance-energy density (XCRM "capacity")
    rho_c: float = 1.0

    # Choose initial branch sign for H: -1 contracting, +1 expanding
    H_sign_init: int = -1

    # Safety epsilon
    eps: float = 1e-12


def V(R: float, p: Params) -> float:
    """Quadratic relaxation potential around R_bg."""
    x = (R - p.R_bg)
    return 0.5 * (p.m ** 2) * (x ** 2)


def dVdR(R: float, p: Params) -> float:
    """Derivative of V wrt R."""
    return (p.m ** 2) * (R - p.R_bg)


def rho_R(R: float, Rdot: float, p: Params) -> float:
    """Resistance energy density."""
    return 0.5 * (Rdot ** 2) + V(R, p)


def rho_eff(rho: float, p: Params) -> float:
    """
    STUR saturation closure (bounce mechanism):
      ρ_eff = ρ (1 - ρ/ρ_c)

    - For small ρ: standard-like behavior (ρ_eff ≈ ρ)
    - As ρ → ρ_c: ρ_eff → 0, forcing H → 0 (bounce)
    - For ρ > ρ_c: we clamp to 0 for numerical stability (unphysical region)
      In a full STUR PDE, the evolution should prevent overshoot.
    """
    if rho <= 0:
        return 0.0
    r = rho / (p.rho_c + p.eps)
    val = rho * (1.0 - r)
    return float(max(0.0, val))


def Hubble(R: float, Rdot: float, p: Params, H_sign: int) -> float:
    """Friedmann closure with chosen branch sign."""
    rho = rho_R(R, Rdot, p)
    heff = rho_eff(rho, p)
    return float(H_sign) * np.sqrt(heff / 3.0 + p.eps)


# ===============================================================
# ODE system
# ===============================================================

def stur_system(t: float, y: np.ndarray, p: Params) -> np.ndarray:
    """
    State y = [a, R, Rdot, H_sign_float]
    We keep H_sign as a continuous state but round it to ±1 in dynamics.

    a_dot = a * H
    R_dot = Rdot
    Rddot = -3 H Rdot - dV/dR

    Branch rule:
    - H_sign stays fixed until we cross the bounce (H ~ 0 near rho~rho_c),
      then we flip sign to represent contraction→expansion (or reverse).
    - This is the minimal way to represent a bounce in first-order form.
    """
    a, R, Rdot, Hs = y
    H_sign = -1 if Hs < 0 else +1

    # Compute H on the current branch
    H = Hubble(R, Rdot, p, H_sign)

    # Bounce detector: near H ~ 0 while rho near rho_c
    rho = rho_R(R, Rdot, p)
    near_bounce = (abs(H) < 5e-4) and (rho > 0.92 * p.rho_c)

    # Flip the branch at bounce so the solution continues smoothly
    # (contracting H<0 -> expanding H>0). In full GR you'd track a_dot sign;
    # here we explicitly switch the square-root branch.
    if near_bounce and H_sign < 0:
        H_sign = +1

    # Dynamics
    adot = a * H
    dR = Rdot
    dRdot = -3.0 * H * Rdot - dVdR(R, p)

    # Keep sign state consistent (piecewise constant; we encode the flip implicitly)
    dHs = 0.0

    return np.array([adot, dR, dRdot, dHs], dtype=float)


# ===============================================================
# Simulation driver
# ===============================================================

def _rk4_fallback(
    p: Params,
    t_span: Tuple[float, float],
    n: int,
    a0: float,
    R0: float,
    Rdot0: float,
) -> Dict[str, np.ndarray]:
    """
    SciPy-free RK4 fallback so the same model runs in JupyterLite.
    Integrates the same first-order system y' = f(t,y).
    """
    t = np.linspace(t_span[0], t_span[1], n)
    dt = t[1] - t[0]
    y = np.zeros((4, n), dtype=float)
    y[:, 0] = [a0, R0, Rdot0, float(-1 if p.H_sign_init < 0 else +1)]

    for i in range(n - 1):
        ti = t[i]
        yi = y[:, i]

        k1 = stur_system(ti, yi, p)
        k2 = stur_system(ti + 0.5 * dt, yi + 0.5 * dt * k1, p)
        k3 = stur_system(ti + 0.5 * dt, yi + 0.5 * dt * k2, p)
        k4 = stur_system(ti + dt, yi + dt * k3, p)

        y[:, i + 1] = yi + (dt / 6.0) * (k1 + 2 * k2 + 2 * k3 + k4)

        # keep a positive to avoid log issues in diagnostics
        if y[0, i + 1] < p.eps:
            y[0, i + 1] = p.eps

    a = y[0]
    R = y[1]
    Rdot = y[2]

    H = np.gradient(np.log(np.maximum(a, p.eps)), t)
    rho = np.array([rho_R(R[i], Rdot[i], p) for i in range(len(t))], dtype=float)
    rhoe = np.array([rho_eff(rho[i], p) for i in range(len(t))], dtype=float)

    idx_b = int(np.argmin(np.abs(H)))
    t_b = float(t[idx_b])

    return {
        "t": t,
        "a": a,
        "H": H,
        "R": R,
        "Rdot": Rdot,
        "rho_R": rho,
        "rho_eff": rhoe,
        "t_bounce": np.array([t_b]),
        "idx_bounce": np.array([idx_b]),
    }


def run_sim(
    p: Params,
    t_span: Tuple[float, float] = (-20.0, 20.0),
    n: int = 2500,
    a0: float = 1.0,
    R0: float = 0.0,
    Rdot0: float = 1.15,
) -> Dict[str, np.ndarray]:
    """
    Choose initial conditions:
    - a0 arbitrary normalization
    - R0, Rdot0 set total resistance-energy density
    - Start on contracting branch (H_sign_init=-1) to show a bounce
    """
    if _HAVE_SCIPY:
        Hs0 = float(-1 if p.H_sign_init < 0 else +1)
        y0 = np.array([a0, R0, Rdot0, Hs0], dtype=float)
        t_eval = np.linspace(t_span[0], t_span[1], n)

        sol = solve_ivp(
            fun=lambda t, y: stur_system(t, y, p),
            t_span=t_span,
            y0=y0,
            t_eval=t_eval,
            rtol=1e-8,
            atol=1e-10,
            method="RK45",
        )

        if not sol.success:
            raise RuntimeError(f"Integration failed: {sol.message}")

        a = sol.y[0]
        R = sol.y[1]
        Rdot = sol.y[2]

        # Reconstruct H with a sign chosen from a_dot/a (numerical)
        H = np.gradient(np.log(np.maximum(a, p.eps)), sol.t)

        rho = np.array([rho_R(R[i], Rdot[i], p) for i in range(len(sol.t))], dtype=float)
        rhoe = np.array([rho_eff(rho[i], p) for i in range(len(sol.t))], dtype=float)

        idx_b = int(np.argmin(np.abs(H)))
        t_b = float(sol.t[idx_b])

        return {
            "t": sol.t,
            "a": a,
            "H": H,
            "R": R,
            "Rdot": Rdot,
            "rho_R": rho,
            "rho_eff": rhoe,
            "t_bounce": np.array([t_b]),
            "idx_bounce": np.array([idx_b]),
        }

    # Fallback (JupyterLite-safe)
    return _rk4_fallback(p, t_span, n, a0, R0, Rdot0)

# ===============================================================

def main():
    p = Params(
        R_bg=0.0,
        m=0.45,
        rho_c=1.0,
        H_sign_init=-1,  # start contracting -> bounce -> expand
    )

    data = run_sim(
        p=p,
        t_span=(-20.0, 20.0),
        n=2600,
        a0=1.0,
        R0=0.0,
        Rdot0=1.15,
    )

    t = data["t"]
    a = data["a"]
    H = data["H"]
    rho = data["rho_R"]
    rhoe = data["rho_eff"]
    tb = float(data["t_bounce"][0])
    ib = int(data["idx_bounce"][0])

    # ---- Plots ----
    fig, ax = plt.subplots(figsize=(8.5, 4.5))
    ax.plot(t, a, lw=1.6)

    ax.set_title("STUR Bounce Toy Model — Scale Factor a(t)")
    ax.set_xlabel("t (dimensionless)")
    ax.set_ylabel("a(t)")

        },
