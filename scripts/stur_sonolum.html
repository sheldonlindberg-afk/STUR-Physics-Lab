Multi-fluid, multi-bubble sonoluminescence from a driven Rayleigh–Plesset bubble with a 5D χ-torsion channel.

How to Use

1. Click OPEN IN JUPYTER PIODE, create a new notebook, and paste the full script below into a cell.
2. Run the cell. The simulator will:

  • Loop over 9 “ambient + gas” setups: H2O, D2O, Ar, Xe, He, SF6, C2F6, CCl4, Air.
  • For each fluid, run a Monte-Carlo ensemble (~60 bubbles) with slightly different R0, drive amplitude, and frequency.
  • Integrate a physically grounded Rayleigh–Plesset equation for R(t) and compute T(t) from adiabatic compression.
  • Track minimum collapse radius Rmin/R0, peak temperature Tmax, Wien-like peak wavelength λpeak, and maximum χ excitation per bubble.
  • Show bar plots of mean Tmax, Rmin, and χ excitation per fluid and print a JSON dictionary with all samples.

3. You can recycle the JSON into your own notebooks to fit distributions, compare against SL spectra, or plug into other STUR labs.

Physical Model – RP Collapse + Adiabatic Heating + χ Channel

At the core is a single spherical bubble of equilibrium radius R0 in a fluid of density ρ, viscosity μ, and surface tension σ. The radius R(t) obeys a standard Rayleigh–Plesset–type equation driven by an acoustic field PA sin(2π f t): 

R R̈ + (3/2) Ṙ² = (1/ρ) [
  P_g(R) - P_∞ - P_A sin(2π f t)
  - 2σ/R - 4μ Ṙ / R
]

P_g(R) = P_g0 (R₀ / R)^(3γ)

where:

  • P_∞ ≈ 1 atm is the ambient pressure.
  • P_g0 is the internal gas pressure at equilibrium.
  • γ is the effective polytropic index of the gas (≈1.33 for water vapor, 5/3 for noble gases).
  • f is the acoustic drive frequency (here around 26 kHz).

Instead of guessing a temperature ODE, we use the adiabatic law directly: 

T(t) = T₀ (R₀ / R(t))^(3(γ - 1))

with T0 ≈ 293 K. To keep the numerics sane and closer to experimental SL regimes, we clamp: 

T(t) ∈ [10³ K, 5 × 10⁴ K]

This gives more realistic trends in the plots: noble-gas-dominated bubbles reach hotter, shorter-wavelength flashes than water-like or heavy, highly damped fluids.

The 5D χ torsion degree of freedom is modeled as a curvature channel that lights up when the bubble compresses: 

dχ/dt = Γχ (R₀ / R - 1)

χ_amp = max_t |χ(t)|

so each collapse pumps χ when R < R0. In STUR language, the bubble is a tiny torsion cavity that shoves part of the collapse energy sideways into χ and then radiates it back out as a flash.

Full Python Script (JupyterLite / Piode Safe)

#!/usr/bin/env python3
# =====================================================================
# STUR 5D χ-COUPLED MULTI-FLUID SONOLUMINESCENCE ENGINE v5.2
# - 9 fluids: H2O, D2O, Ar, Xe, He, SF6, C2F6, CCl4, Air
# - ~60 bubble trajectories per fluid (Monte-Carlo)
# - Rayleigh–Plesset collapse with acoustic drive
# - Adiabatic compression for T(t) + χ torsion channel
# - Summary plots + JSON output (no SciPy, JupyterLite-safe)
# =====================================================================

import numpy as np
import matplotlib.pyplot as plt
import json

plt.style.use("dark_background")

# ---------------------------------------------------------------------
# 1. Fluid database (ambient + effective gas parameters)
# ---------------------------------------------------------------------
fluids = {
    "H2O":  {"rho": 997.0,  "gamma": 1.33, "visc": 1.0e-3,  "sigma": 0.072, "Pg0": 1.0e5, "ion_E": 12.1},
    "D2O":  {"rho": 1105.0, "gamma": 1.33, "visc": 1.25e-3, "sigma": 0.072, "Pg0": 1.0e5, "ion_E": 12.1},
    "Ar":   {"rho": 1.78,   "gamma": 5.0/3.0, "visc": 2.2e-5, "sigma": 0.013, "Pg0": 1.0e5, "ion_E": 15.8},
    "Xe":   {"rho": 5.9,    "gamma": 5.0/3.0, "visc": 2.3e-5, "sigma": 0.012, "Pg0": 1.0e5, "ion_E": 12.3},
    "He":   {"rho": 0.18,   "gamma": 5.0/3.0, "visc": 1.9e-5, "sigma": 0.072, "Pg0": 1.0e5, "ion_E": 24.6},
    "SF6":  {"rho": 6.17,   "gamma": 1.10, "visc": 1.5e-5, "sigma": 0.011, "Pg0": 1.0e5, "ion_E": 15.2},
    "C2F6": {"rho": 5.8,    "gamma": 1.13, "visc": 1.1e-5, "sigma": 0.012, "Pg0": 1.0e5, "ion_E": 14.8},
    "CCl4": {"rho": 1590.0, "gamma": 1.12, "visc": 9.0e-4, "sigma": 0.027, "Pg0": 1.0e5, "ion_E": 11.4},
    "Air":  {"rho": 1.23,   "gamma": 1.40, "visc": 1.8e-5, "sigma": 0.072, "Pg0": 1.0e5, "ion_E": 13.6}
}

# ---------------------------------------------------------------------
# 2. Global constants and χ-coupling strength
# ---------------------------------------------------------------------
P_INF   = 1.0e5       # ambient pressure (Pa)
T0      = 293.0       # ambient temperature (K)
F0      = 26.0e3      # nominal drive frequency (Hz)
R0_MEAN = 4.5e-6      # mean equilibrium radius (m)
CHI_RATE = 5.0e6      # χ response rate (sets how fast torsion responds)

# ---------------------------------------------------------------------
# 3. Single-bubble trajectory (Rayleigh–Plesset + adiabatic T + χ)
# ---------------------------------------------------------------------
def run_traj(seed, fluid_name, steps=4000, n_cycles=3):
    """
    Integrate one bubble in a given fluid using a 2nd-order explicit scheme.
    State: R(t), Rdot(t), χ(t).
    """
    fd = fluids[fluid_name]
    rho   = fd["rho"]
    gamma = fd["gamma"]
    mu    = fd["visc"]
    sigma = fd["sigma"]
    Pg0   = fd["Pg0"]

    rng = np.random.default_rng(seed)

    # Randomize R0, drive frequency, and amplitude per bubble
    R0 = R0_MEAN * (1.0 + 0.15 * rng.normal())
    R0 = max(R0, 1.0e-6)

    f = F0 * (1.0 + 0.05 * rng.normal())
    omega = 2.0 * np.pi * f

    # Acoustic pressure amplitude around 1.4 atm with some spread
    PA = 1.4e5 * (1.0 + 0.3 * rng.normal())

    t_end = n_cycles / f
    dt    = t_end / steps

    # Initial conditions
    R   = R0
    Rdot = 0.0
    chi  = 0.0

    R_hist   = []
    T_hist   = []
    chi_hist = []

    for i in range(steps):
        t = i * dt

        # Keep R physically meaningful
        R = max(R, 0.05 * R0)

        # Rayleigh–Plesset RHS at (R, Rdot)
        Pac = PA * np.sin(omega * t)
        Pg  = Pg0 * (R0 / R)**(3.0 * gamma)

        # Pressure balance term
        term = (Pg - P_INF - Pac - 2.0 * sigma / R - 4.0 * mu * Rdot / max(R, 1.0e-12)) / rho
        Rdd  = (term - 1.5 * Rdot * Rdot) / R

        # Simple 2nd-order step (midpoint)
        R_mid     = R + 0.5 * dt * Rdot
        R_mid     = max(R_mid, 0.05 * R0)
        Rdot_mid  = Rdot + 0.5 * dt * Rdd

        Pac_mid = PA * np.sin(omega * (t + 0.5 * dt))
        Pg_mid  = Pg0 * (R0 / R_mid)**(3.0 * gamma)
        term_mid = (Pg_mid - P_INF - Pac_mid - 2.0 * sigma / R_mid
                    - 4.0 * mu * Rdot_mid / max(R_mid, 1.0e-12)) / rho
        Rdd_mid = (term_mid - 1.5 * Rdot_mid * Rdot_mid) / R_mid

        # Update
        Rdot += dt * Rdd_mid
        R    += dt * Rdot

        # Safety clips
        if R < 0.05 * R0:
            R = 0.05 * R0
            Rdot = 0.0
        if R > 5.0 * R0:
            R = 5.0 * R0

        # Adiabatic temperature with soft physical clamp
        T_ad = T0 * (R0 / R)**(3.0 * (gamma - 1.0))
        T = min(max(T_ad, 1.0e3), 5.0e4)

        # χ torsion channel: only excited when R < R0
        chi += CHI_RATE * (R0 / R - 1.0) * dt

        # Store
        R_hist.append(R / R0)  # dimensionless radius
        T_hist.append(T)
        chi_hist.append(chi)

    return np.array(R_hist), np.array(T_hist), np.array(chi_hist)

# ---------------------------------------------------------------------
# 4. Monte-Carlo ensemble for one fluid
# ---------------------------------------------------------------------
def run_multibubble(fluid_name, N=60):
    Rmins   = []
    Tmaxs   = []
    Lambdas = []
    ChiAmp  = []

    for i in range(N):
        R, T, chi = run_traj(i, fluid_name)

        Rmins.append(float(np.min(R)))
        Tmaxs.append(float(np.max(T)))

        Tmax_val = max(float(np.max(T)), 1.0e3)
        # Wien-like peak wavelength (m)
        lambda_peak = 2.898e-3 / Tmax_val
        Lambdas.append(lambda_peak)

        ChiAmp.append(float(np.max(np.abs(chi))))

    return (np.array(Rmins),
            np.array(Tmaxs),
            np.array(Lambdas),
            np.array(ChiAmp))

# ---------------------------------------------------------------------
# 5. Run all fluids and collect statistics
# ---------------------------------------------------------------------
results = {}
fluids_order = list(fluids.keys())

print("=== STUR 5D χ Sonoluminescence Lab v5.2 ===")
for name in fluids_order:
    print("Running:", name)
    Rmins, Tmaxs, Lambdas, ChiAmp = run_multibubble(name, N=60)
    results[name] = {
        "Rmin":   Rmins.tolist(),
        "Tmax":   Tmaxs.tolist(),
        "lambda": Lambdas.tolist(),
        "chiamp": ChiAmp.tolist()
    }

print("Simulation complete.")

# ---------------------------------------------------------------------
# 6. Summary bar plots (mean stats per fluid)
# ---------------------------------------------------------------------
mean_T    = [np.mean(results[f]["Tmax"]) for f in fluids_order]
mean_Rmin = [np.mean(results[f]["Rmin"]) for f in fluids_order]
mean_chi  = [np.mean(results[f]["chiamp"]) for f in fluids_order]
mean_lam  = [np.mean(results[f]["lambda"]) for f in fluids_order]

xpos = np.arange(len(fluids_order))

fig, ax = plt.subplots(1, 3, figsize=(14, 4))

# Panel 1: peak temperature
ax[0].bar(xpos, np.array(mean_T) / 1000.0)
ax[0].set_xticks(xpos)
ax[0].set_xticklabels(fluids_order, rotation=45)
ax[0].set_ylabel("T_max (kK)")
ax[0].set_title("Mean peak temperature")

# Panel 2: minimum radius
ax[1].bar(xpos, mean_Rmin)
ax[1].set_xticks(xpos)
ax[1].set_xticklabels(fluids_order, rotation=45)
ax[1].set_ylabel("R_min / R0")
ax[1].set_title("Mean minimum radius")

# Panel 3: χ excitation
ax[2].bar(xpos, mean_chi)
ax[2].set_xticks(xpos)
ax[2].set_xticklabels(fluids_order, rotation=45)
ax[2].set_ylabel("max |χ|")
ax[2].set_title("Mean χ excitation")

plt.tight_layout()
plt.show()

# ---------------------------------------------------------------------
# 7. JSON output
# ---------------------------------------------------------------------
print(json.dumps(results, indent=2))

Reading the Results

Each fluid entry in the JSON has four arrays (length ≈ 60):

  • Rmin – minimum dimensionless radius R/R0 per bubble.
  • Tmax – peak temperature (K) from adiabatic compression during collapse.
  • lambda – approximate Wien peak wavelength (m), λ ≈ 2.9×10−3 / Tmax.
  • chiamp – maximum |χ| reached, a proxy for torsion–resistance excitation.

In this STUR picture, noble-gas bubbles (Ar, Xe, He) tend to reach smaller Rmin, hotter Tmax, and shorter λ than water-like or heavy, viscously damped fluids. The χ bar is the “extra” channel: how much of the collapse was forced sideways into a 5D torsion cavity before it snapped back as light.

You can swap in your own fluid parameters, drive spectra, or χ-coupling to explore where the flash turns UV-hard, where it dies out, and where STUR predicts the cleanest energy focusing.
