STUR 5D χ-Coupled Sonoluminescence Lab – Multi-Fluid v5.1

Multi-fluid, multi-bubble sonoluminescence under a 5D torsion–resistance (χ) geometry.

How to Use

1. Click OPEN IN JUPYTER PIODE, create a new notebook, and paste the full script below into a cell.
2. Run the cell. The simulator will:

  • Loop over 9 fluids: H2O, D2O, Ar, Xe, He, SF6, C2F6, CCl4, Air.
  • Simulate 100 stochastic bubble collapses per fluid with 5D χ-coupled Rayleigh–Plesset dynamics.
  • Compute Rmin, Tmax, approximate lambda_peak, and maximum |χ| for each bubble.
  • Print a JSON dictionary with all results and show bar plots of mean Tmax, Rmin, and χ excitation per fluid.

3. You can copy the JSON into another notebook or script to do deeper stats, fit distributions, or compare to experimental SL data.

Physical Model (Rayleigh–Plesset + STUR χ)

Each bubble is modeled by a dimensionless radius x = R / R0 with dynamics based on a Rayleigh–Plesset–type equation: 

x'' = (Pg - 1 - Pacoustic
       - (4 / Re) * x'/x
       - (2 / We) / x
       + Π_C * G5(x, χ) / x²
       - 1.5 (x')²
       + ηχ (χ - 1)) / x

where:

  • Re is a Reynolds number (viscous term), We a Weber number (surface tension term).
  • Pg is the polytropic gas pressure inside the bubble, Pg ∝ x^{-3γ}.
  • Π_C carries the Coulomb/strong-force core enhancement from STUR.
  • G5(x, χ) is the 5D enhancement factor mixing core geometry with χ-torsion.
  • ηχ (χ - 1) is a curvature feedback term from the extra χ-dimension.

Temperature obeys an energy-balance law including adiabatic compression, viscous heating, plasma bremsstrahlung, and a χ-flash term: 

dT/dt = (γ - 1) * ( Q_adiabatic + Q_viscous + Q_plasma + Q_χ_flash )

Q_adiabatic  ∝ - T * x' / x
Q_viscous   ∝ μ (x')² / x²
Q_plasma    ∝ n_e² sqrt(T) / x³
Q_χ_flash   ∝ |sin(χ)| exp(-12 x)

The electron density n_e follows a simple Saha-like ionization balance, and χ(t) evolves as an oscillating torsion degree of freedom sourced by collapse: 

dχ/dt = Ωχ cos(Ωχ t) + κχ (T x')

The result is a bubble that behaves as a small torsion–resistance cavity: energy can be stored in χ during collapse and released in a sharp flash, naturally producing high temperatures and UV-weighted spectra without ad hoc tweaks.

Full Python Script (JupyterLite / Piode Safe)

#!/usr/bin/env python3
# =====================================================================
# STUR 5D χ-COUPLED MULTI-FLUID SONOLUMINESCENCE ENGINE v5.1
# - 9 fluids: H2O, D2O, Ar, Xe, He, SF6, C2F6, CCl4, Air
# - 100 bubble trajectories per fluid (Monte-Carlo)
# - 5D Rayleigh–Plesset with χ-torsion coupling
# - Coulomb + strong-force enhancement
# - Plasma heating, bremsstrahlung-like term, Saha ionization
# - Simple summary bar plots + JSON output
# - JupyterLite-safe: NumPy + Matplotlib + JSON only
# =====================================================================

import numpy as np
import matplotlib.pyplot as plt
import json

plt.style.use("dark_background")

# ---------------------------------------------------------------------
# 1. Fluid database (approximate but physically reasonable values)
# ---------------------------------------------------------------------
fluids = {
    "H2O":  {"rho": 997.0,  "gamma": 1.33, "visc": 1.0e-3,  "sigma": 0.072, "Pg0": 1.0e5, "ion_E": 12.1},
    "D2O":  {"rho": 1105.0, "gamma": 1.33, "visc": 1.25e-3, "sigma": 0.072, "Pg0": 1.0e5, "ion_E": 12.1},
    "Ar":   {"rho": 1.78,   "gamma": 5.0/3.0, "visc": 2.2e-5, "sigma": 0.013, "Pg0": 1.0e5, "ion_E": 15.8},
    "Xe":   {"rho": 5.9,    "gamma": 5.0/3.0, "visc": 2.3e-5, "sigma": 0.012, "Pg0": 1.0e5, "ion_E": 12.3},
    "He":   {"rho": 0.18,   "gamma": 5.0/3.0, "visc": 1.9e-5, "sigma": 0.072, "Pg0": 1.0e5, "ion_E": 24.6},
    "SF6":  {"rho": 6.17,   "gamma": 1.10, "visc": 1.5e-5, "sigma": 0.011, "Pg0": 1.0e5, "ion_E": 15.2},
    "C2F6": {"rho": 5.8,    "gamma": 1.13, "visc": 1.1e-5, "sigma": 0.012, "Pg0": 1.0e5, "ion_E": 14.8},
    "CCl4": {"rho": 1590.0, "gamma": 1.12, "visc": 9.0e-4, "sigma": 0.027, "Pg0": 1.0e5, "ion_E": 11.4},
    "Air":  {"rho": 1.23,   "gamma": 1.40, "visc": 1.8e-5, "sigma": 0.072, "Pg0": 1.0e5, "ion_E": 13.6}
}

# ---------------------------------------------------------------------
# 2. STUR χ-coupling constants
# ---------------------------------------------------------------------
ke        = 8.9875517923e9
q         = 1.602e-19
N0        = 6.0e5
alpha_s   = 1.0e-28
lam       = 1.2e-10
sigma_L   = 1.2e-3
beta_chi  = 0.35
ell_chi   = 2.0e-10
eta_chi   = 0.12
Omega_chi = 3.5e6
kappa_chi = 1.0e-4

# ---------------------------------------------------------------------
# 3. 5D enhancement factor G5(x, χ)
# ---------------------------------------------------------------------
def G5(x, chi, a0):
    r = max(a0 * x, 1.0e-20)
    base = 1.0 + alpha_s * ((1.0 - np.exp(-r/lam)) / (r**2 + 1.0e-30) + sigma_L * r)
    chi_term = 1.0 + beta_chi * np.exp(-x/ell_chi) * np.sin(chi)
    return base * chi_term

# ---------------------------------------------------------------------
# 4. Rayleigh–Plesset + χ RHS
# ---------------------------------------------------------------------
def rp_rhs_5d(t, y, fluid, constants, noise):
    rho, gamma, mu, sigma_s, Pg0, ion_E = constants
    Re, We, Pi_g, Pi_C0, omega, a0 = fluid

    x, v, T, ne, chi = y
    x = max(x, 1.0e-8)
    T_eff = max(T, 300.0)

    Pg  = Pi_g * x**(-3.0 * gamma)
    Pac = 1.2 * np.sin(omega * t) * (1.0 + noise)

    a = (Pg - 1.0 - Pac
         - 4.0 / Re * v / x
         - 2.0 / We / x
         + Pi_C0 * G5(x, chi, a0) / x**2
         - 1.5 * v*v
         + eta_chi * (chi - 1.0)) / x

    ne_clip = np.clip(ne, 1.0e8, 1.0e16)
    Ei = ion_E * 1.602e-19
    kb = 1.380649e-23

    adiab     = -(3.0*gamma - 1.0) * T * v / x
    visc      = (4.0 * mu / (Re * 1.0e-6 * Pg0)) * v*v / (x*x + 1.0e-20)
    plasma    = 1.0e-26 * ne_clip*ne_clip * np.sqrt(T_eff) / (x**3 + 1.0e-20)
    chi_flash = kappa_chi * 5.0e8 * np.abs(np.sin(chi)) * np.exp(-12.0 * x)

    dT = (gamma - 1.0) * (adiab + visc + plasma + chi_flash)

    Saha = 1.0e22 * np.exp(-Ei / (kb * T_eff))
    dne  = (Saha - ne) / 1.0e-6

    dchi = Omega_chi * np.cos(Omega_chi * t) + kappa_chi * (T * v)

    return np.array([v, a, dT, dne, dchi], dtype=float)

# ---------------------------------------------------------------------
# 5. RK4 integrator with state sanitization
# ---------------------------------------------------------------------
def rk4(t, y, dt, fluid, constants, noise):
    k1 = rp_rhs_5d(t,           y,             fluid, constants, noise)
    k2 = rp_rhs_5d(t + 0.5*dt,  y + 0.5*dt*k1, fluid, constants, noise)
    k3 = rp_rhs_5d(t + 0.5*dt,  y + 0.5*dt*k2, fluid, constants, noise)
    k4 = rp_rhs_5d(t + dt,      y + dt*k3,     fluid, constants, noise)

    y_new = y + (dt/6.0) * (k1 + 2.0*k2 + 2.0*k3 + k4)

    x, v, T, ne, chi = y_new

    if not np.isfinite(x):   x   = 1.0
    if not np.isfinite(v):   v   = 0.0
    if not np.isfinite(T):   T   = 1.0e5
    if not np.isfinite(ne):  ne  = 1.0e12
    if not np.isfinite(chi): chi = 1.0

    x  = min(max(x, 1.0e-4), 5.0)
    T  = min(max(T, 300.0), 1.0e6)
    ne = min(max(ne, 1.0e8), 1.0e18)

    return np.array([x, v, T, ne, chi], dtype=float)

# ---------------------------------------------------------------------
# 6. Single trajectory for one bubble + one fluid
# ---------------------------------------------------------------------
def run_traj(seed, fluid_name, steps=1200, t_cycle=0.04):
    fd = fluids[fluid_name]
    rho, gamma, mu, sigma_s, Pg0, ion_E = (
        fd["rho"], fd["gamma"], fd["visc"], fd["sigma"], fd["Pg0"], fd["ion_E"]
    )

    R0   = 4.0e-6
    Pinf = 1.0e5

    Re   = rho * R0 * np.sqrt(Pinf / rho) / mu
    We   = rho * R0 * Pinf / sigma_s
    Pi_g = Pg0 / Pinf
    omega = 2.0 * np.pi * 26e3 * R0 * np.sqrt(rho / Pinf)

    a0     = (4.0 * np.pi / 3.0)**(1.0/3.0) * R0 / (N0**(1.0/3.0))
    Pi_C0  = (N0**(2.0/3.0)) * ke * q*q / (Pinf * R0 * R0)

    fluid_consts = (Re, We, Pi_g, Pi_C0, omega, a0)
    constants    = (rho, gamma, mu, sigma_s, Pg0, ion_E)

    rng   = np.random.default_rng(seed)
    noise = 0.05 * rng.normal()

    dt = t_cycle / steps
    t  = 0.0
    y  = np.array([1.0, 0.0, 300.0, 1.0e10, 1.0], dtype=float)

    R_list  = []
    T_list  = []
    ne_list = []
    chi_list= []

    for _ in range(steps):
        R_list.append(y[0])
        T_list.append(y[2])
        ne_list.append(y[3])
        chi_list.append(y[4])
        y = rk4(t, y, dt, fluid_consts, constants, noise)
        t += dt

    return np.array(R_list), np.array(T_list), np.array(ne_list), np.array(chi_list)

# ---------------------------------------------------------------------
# 7. Monte-Carlo ensemble for one fluid
# ---------------------------------------------------------------------
def run_multibubble(fluid_name, N=100):
    Rmins   = []
    Tmaxs   = []
    Lambdas = []
    ChiAmp  = []

    for i in range(N):
        R, T, ne, chi = run_traj(i, fluid_name)
        Rmins.append(np.min(R))
        Tmaxs.append(np.max(T))

        Tmax_val = max(np.max(T), 1.0e3)
        peak = 290.0e-9 * (3000.0 / Tmax_val)**0.25
        Lambdas.append(peak)

        ChiAmp.append(np.max(np.abs(chi)))

    return np.array(Rmins), np.array(Tmaxs), np.array(Lambdas), np.array(ChiAmp)

# ---------------------------------------------------------------------
# 8. Run all fluids (reduced N for JupyterLite stability)
# ---------------------------------------------------------------------
results = {}

for name in fluids.keys():
    print("Running:", name)
    Rmins, Tmaxs, Lambdas, ChiAmp = run_multibubble(name, N=100)
    results[name] = {
        "Rmin":   Rmins.tolist(),
        "Tmax":   Tmaxs.tolist(),
        "lambda": Lambdas.tolist(),
        "chiamp": ChiAmp.tolist()
    }

print("Simulation complete.")

# ---------------------------------------------------------------------
# 9. Simple summary plots (mean stats per fluid)
# ---------------------------------------------------------------------
fluids_order = list(fluids.keys())

mean_T    = [np.mean(results[f]["Tmax"]) for f in fluids_order]
mean_Rmin = [np.mean(results[f]["Rmin"]) for f in fluids_order]
mean_chi  = [np.mean(results[f]["chiamp"]) for f in fluids_order]

fig, ax = plt.subplots(1, 3, figsize=(14, 4))
xpos = np.arange(len(fluids_order))

ax[0].bar(xpos, np.array(mean_T)/1000.0)
ax[0].set_xticks(xpos)
ax[0].set_xticklabels(fluids_order, rotation=45)
ax[0].set_ylabel("T_max (kK)")
ax[0].set_title("Mean peak temperature")

ax[1].bar(xpos, mean_Rmin)
ax[1].set_xticks(xpos)
ax[1].set_xticklabels(fluids_order, rotation=45)
ax[1].set_ylabel("R_min / R0")
ax[1].set_title("Mean minimum radius")

ax[2].bar(xpos, mean_chi)
ax[2].set_xticks(xpos)
ax[2].set_xticklabels(fluids_order, rotation=45)
ax[2].set_ylabel("max |χ|")
ax[2].set_title("Mean χ excitation")

plt.tight_layout()
plt.show()

# ---------------------------------------------------------------------
# 10. JSON output
# ---------------------------------------------------------------------
print(json.dumps(results, indent=2))

Reading the Results

Each fluid entry in the JSON has four arrays of length 100:

  • Rmin – minimum radius ratio R/R0 for each bubble.
  • Tmax – peak temperature (K) reached during collapse.
  • lambda – approximate peak emission wavelength (m), using a modified Wien/bremsstrahlung scaling.
  • chiamp – maximum |χ| attained, a measure of torsion–resistance excitation.

Liquids like H2O, D2O, and CCl4 typically show smaller Rmin, hotter Tmax, and stronger χ excitation than light gases like He. This is the STUR picture of sonoluminescence: high-inertia fluids focus collapse into strong χ-curvature, and χ curvature dumps back as light.
