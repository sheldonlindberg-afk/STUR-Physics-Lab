What This Page Tests

Observable: Peak temperature \(T_{\max}\), minimum radius \(R_{\min}/R_0\), and chi-excitation \(|\chi|_{\max}\) for collapsing sonoluminescent bubbles.

Geometry: Spherical bubble of equilibrium radius \(R_0 \approx 4.5\,\mu\text{m}\) driven at \(f \approx 26\,\text{kHz}\) acoustic frequency.

Regime: Rayleigh-Plesset collapse with adiabatic heating and 5D torsion coupling.

Model

Starting point: The STUR master action from Foundations:

\[ S[R,g,X] = \int d^4x\,\sqrt{-g}\;\Bigl[ \underbrace{\alpha\,(\nabla R)^2}_{\color{#4ade80}\text{diffusion}} \;-\; \underbrace{V(R)}_{\color{#f472b6}\text{potential}} \;+\; \underbrace{\beta\,(\partial_t X)^2}_{\color{#fbbf24}\text{XCRM}} \;-\; \underbrace{U(X - R)}_{\color{#fbbf24}\text{coupling}} \;+\; \underbrace{L_{\text{torsion}}}_{\color{#60a5fa}\text{gravity}} \;+\; \underbrace{L_{\text{matter}}}_{\color{#22d3ee}\text{fields}} \Bigr] \]
Master Action (v9.2)

Rayleigh-Plesset equation: The bubble radius \(R(t)\) obeys:

\[ R\ddot{R} + \frac{3}{2}\dot{R}^2 = \frac{1}{\rho}\left[P_g(R) - P_\infty - P_A\sin(2\pi f t) - \frac{2\sigma}{R} - \frac{4\mu\dot{R}}{R}\right] \]
Rayleigh-Plesset Dynamics

Adiabatic heating: Temperature from compression ratio:

\[ T(t) = T_0 \left(\frac{R_0}{R(t)}\right)^{3(\gamma-1)}, \quad P_g(R) = P_{g0}\left(\frac{R_0}{R}\right)^{3\gamma} \]
Adiabatic Temperature Law

5D chi-torsion channel: The bubble acts as a torsion cavity (see Appendix E.2 for dimensional analysis and derivation):

\[ \frac{d\chi}{dt} = \Gamma_\chi \left(\frac{R_0}{R} - 1\right), \quad \chi_{\text{amp}} = \max_t|\chi(t)| \]
Chi-Torsion Excitation (Eq. E.6)

Key parameter: \(\Gamma_\chi = \alpha/\ell_{\rm coh}\) (Eq. E.9), where \(\alpha\) is the torsion coupling. The chi variable is dimensionless per Eq. E.7, representing accumulated phase excitation.

Prediction

STUR predicts:

  • Noble gas enhancement: Ar, Xe, He reach hotter \(T_{\max}\) and shorter \(\lambda_{\text{peak}}\) than water-like fluids.
  • Chi-excitation scaling: \(\chi_{\text{amp}} \propto (R_0/R_{\min} - 1)\) during collapse.
  • Wien peak: \(\lambda_{\text{peak}} = 2.898 \times 10^{-3} / T_{\max}\) for blackbody-like emission.

Competitor model (Classical SL): No 5D torsion channel; pure thermodynamic collapse without geometric coupling.

#!/usr/bin/env python3
# =====================================================================
# STUR 5D Chi-Coupled Multi-Fluid Sonoluminescence Engine (v9.2)
#
# Tests chi-torsion coupling: d(chi)/dt = Gamma_chi * (R0/R - 1)
#
# 9 fluids: H2O, D2O, Ar, Xe, He, SF6, C2F6, CCl4, Air
# ~60 bubble trajectories per fluid (Monte-Carlo)
# Rayleigh-Plesset collapse with acoustic drive
# Adiabatic compression for T(t) + chi torsion channel
#
# Outputs:
#   - stur_sonolum.json (full results + falsification flag)
#   - Bar plots of T_max, R_min, chi_amp per fluid
#
# Falsified if: chi uncorrelated with R0/Rmin OR T_max fails scaling
# =====================================================================

import numpy as np
import matplotlib.pyplot as plt
import json, time

plt.style.use("dark_background")

# ---------------------------------------------------------------------
# 1. Fluid database (ambient + effective gas parameters)
# ---------------------------------------------------------------------
fluids = {
    "H2O":  {"rho": 997.0,  "gamma": 1.33, "visc": 1.0e-3,  "sigma": 0.072, "Pg0": 1.0e5, "ion_E": 12.1},
    "D2O":  {"rho": 1105.0, "gamma": 1.33, "visc": 1.25e-3, "sigma": 0.072, "Pg0": 1.0e5, "ion_E": 12.1},
    "Ar":   {"rho": 1.78,   "gamma": 5.0/3.0, "visc": 2.2e-5, "sigma": 0.013, "Pg0": 1.0e5, "ion_E": 15.8},
    "Xe":   {"rho": 5.9,    "gamma": 5.0/3.0, "visc": 2.3e-5, "sigma": 0.012, "Pg0": 1.0e5, "ion_E": 12.3},
    "He":   {"rho": 0.18,   "gamma": 5.0/3.0, "visc": 1.9e-5, "sigma": 0.072, "Pg0": 1.0e5, "ion_E": 24.6},
    "SF6":  {"rho": 6.17,   "gamma": 1.10, "visc": 1.5e-5, "sigma": 0.011, "Pg0": 1.0e5, "ion_E": 15.2},
    "C2F6": {"rho": 5.8,    "gamma": 1.13, "visc": 1.1e-5, "sigma": 0.012, "Pg0": 1.0e5, "ion_E": 14.8},
    "CCl4": {"rho": 1590.0, "gamma": 1.12, "visc": 9.0e-4, "sigma": 0.027, "Pg0": 1.0e5, "ion_E": 11.4},
    "Air":  {"rho": 1.23,   "gamma": 1.40, "visc": 1.8e-5, "sigma": 0.072, "Pg0": 1.0e5, "ion_E": 13.6}
}

# ---------------------------------------------------------------------
# 2. Global constants and chi-coupling strength (v9.2)
# ---------------------------------------------------------------------
P_INF   = 1.0e5       # ambient pressure (Pa)
T0      = 293.0       # ambient temperature (K)
F0      = 26.0e3      # nominal drive frequency (Hz)
R0_MEAN = 4.5e-6      # mean equilibrium radius (m)
CHI_RATE = 5.0e6      # chi response rate (sets how fast torsion responds)

OUT_JSON = "stur_sonolum.json"

# ---------------------------------------------------------------------
# 3. Single-bubble trajectory (Rayleigh-Plesset + adiabatic T + chi)
# ---------------------------------------------------------------------
def run_traj(seed, fluid_name, steps=4000, n_cycles=3):
    """
    Integrate one bubble in a given fluid using a 2nd-order explicit scheme.
    State: R(t), Rdot(t), chi(t).
    """
    fd = fluids[fluid_name]
    rho   = fd["rho"]
    gamma = fd["gamma"]
    mu    = fd["visc"]
    sigma = fd["sigma"]
    Pg0   = fd["Pg0"]

    rng = np.random.default_rng(seed)

    # Randomize R0, drive frequency, and amplitude per bubble
    R0 = R0_MEAN * (1.0 + 0.15 * rng.normal())
    R0 = max(R0, 1.0e-6)

    f = F0 * (1.0 + 0.05 * rng.normal())
    omega = 2.0 * np.pi * f

    # Acoustic pressure amplitude around 1.4 atm with some spread
    PA = 1.4e5 * (1.0 + 0.3 * rng.normal())

    t_end = n_cycles / f
    dt    = t_end / steps

    # Initial conditions
    R   = R0
    Rdot = 0.0
    chi  = 0.0

    R_hist   = []
    T_hist   = []
    chi_hist = []

    for i in range(steps):
        t = i * dt

        # Keep R physically meaningful
        R = max(R, 0.05 * R0)

        # Rayleigh-Plesset RHS at (R, Rdot)
        Pac = PA * np.sin(omega * t)
        Pg  = Pg0 * (R0 / R)**(3.0 * gamma)

        # Pressure balance term
        term = (Pg - P_INF - Pac - 2.0 * sigma / R - 4.0 * mu * Rdot / max(R, 1.0e-12)) / rho
        Rdd  = (term - 1.5 * Rdot * Rdot) / R

        # Simple 2nd-order step (midpoint)
        R_mid     = R + 0.5 * dt * Rdot
        R_mid     = max(R_mid, 0.05 * R0)
        Rdot_mid  = Rdot + 0.5 * dt * Rdd

        Pac_mid = PA * np.sin(omega * (t + 0.5 * dt))
        Pg_mid  = Pg0 * (R0 / R_mid)**(3.0 * gamma)
        term_mid = (Pg_mid - P_INF - Pac_mid - 2.0 * sigma / R_mid
                    - 4.0 * mu * Rdot_mid / max(R_mid, 1.0e-12)) / rho
        Rdd_mid = (term_mid - 1.5 * Rdot_mid * Rdot_mid) / R_mid

        # Update
        Rdot += dt * Rdd_mid
        R    += dt * Rdot

        # Safety clips
        if R < 0.05 * R0:
            R = 0.05 * R0
            Rdot = 0.0
        if R > 5.0 * R0:
            R = 5.0 * R0

        # Adiabatic temperature with soft physical clamp
        T_ad = T0 * (R0 / R)**(3.0 * (gamma - 1.0))
        T = min(max(T_ad, 1.0e3), 5.0e4)

        # Chi torsion channel: only excited when R < R0 (v9.2)
        chi += CHI_RATE * (R0 / R - 1.0) * dt

        # Store
        R_hist.append(R / R0)  # dimensionless radius
        T_hist.append(T)
        chi_hist.append(chi)

    return np.array(R_hist), np.array(T_hist), np.array(chi_hist)

# ---------------------------------------------------------------------
# 4. Monte-Carlo ensemble for one fluid
# ---------------------------------------------------------------------
def run_multibubble(fluid_name, N=60):
    Rmins   = []
    Tmaxs   = []
    Lambdas = []
    ChiAmp  = []

    for i in range(N):
        R, T, chi = run_traj(i, fluid_name)

        Rmins.append(float(np.min(R)))
        Tmaxs.append(float(np.max(T)))

        Tmax_val = max(float(np.max(T)), 1.0e3)
        # Wien-like peak wavelength (m)
        lambda_peak = 2.898e-3 / Tmax_val
        Lambdas.append(lambda_peak)

        ChiAmp.append(float(np.max(np.abs(chi))))

    return (np.array(Rmins),
            np.array(Tmaxs),
            np.array(Lambdas),
            np.array(ChiAmp))

# ---------------------------------------------------------------------
# 5. Run all fluids and collect statistics
# ---------------------------------------------------------------------
results = {}
fluids_order = list(fluids.keys())

print("=== STUR 5D Chi Sonoluminescence Lab v9.2 ===")
for name in fluids_order:
    print("Running:", name)
    Rmins, Tmaxs, Lambdas, ChiAmp = run_multibubble(name, N=60)
    results[name] = {
        "Rmin":   Rmins.tolist(),
        "Tmax":   Tmaxs.tolist(),
        "lambda": Lambdas.tolist(),
        "chiamp": ChiAmp.tolist()
    }

print("Simulation complete.")

# ---------------------------------------------------------------------
# 6. Summary statistics and falsification check
# ---------------------------------------------------------------------
mean_T    = [np.mean(results[f]["Tmax"]) for f in fluids_order]
mean_Rmin = [np.mean(results[f]["Rmin"]) for f in fluids_order]
mean_chi  = [np.mean(results[f]["chiamp"]) for f in fluids_order]
mean_lam  = [np.mean(results[f]["lambda"]) for f in fluids_order]

# Falsification check
falsified = False
triggered = []

# Kill-1: Chi correlation with 1/Rmin
collapse_ratios = [1.0/r for r in mean_Rmin]
chi_corr = np.corrcoef(collapse_ratios, mean_chi)[0,1]
if chi_corr < 0.5:
    triggered.append("Kill-1: Chi uncorrelated with collapse ratio")
    falsified = True

# Kill-2: Noble gas T_max check (Ar should be hotter than H2O)
ar_idx = fluids_order.index("Ar")
h2o_idx = fluids_order.index("H2O")
if mean_T[ar_idx] < mean_T[h2o_idx]:
    triggered.append("Kill-2: Noble gas T_max lower than H2O")
    falsified = True

# Kill-3: Wien peak deviation (check Ar)
ar_T = mean_T[ar_idx]
ar_lam = mean_lam[ar_idx]
wien_pred = 2.898e-3 / ar_T
wien_dev = abs(ar_lam - wien_pred) / wien_pred
if wien_dev > 0.20:
    triggered.append("Kill-3: Wien peak deviation > 20%")
    falsified = True

# ---------------------------------------------------------------------
# 7. Summary bar plots (mean stats per fluid)
# ---------------------------------------------------------------------
xpos = np.arange(len(fluids_order))

fig, ax = plt.subplots(1, 3, figsize=(14, 4))

# Panel 1: peak temperature
ax[0].bar(xpos, np.array(mean_T) / 1000.0, color='#f59e0b')
ax[0].set_xticks(xpos)
ax[0].set_xticklabels(fluids_order, rotation=45)
ax[0].set_ylabel("T_max (kK)")
ax[0].set_title("Mean peak temperature")

# Panel 2: minimum radius
ax[1].bar(xpos, mean_Rmin, color='#60a5fa')
ax[1].set_xticks(xpos)
ax[1].set_xticklabels(fluids_order, rotation=45)
ax[1].set_ylabel("R_min / R0")
ax[1].set_title("Mean minimum radius")

# Panel 3: chi excitation
ax[2].bar(xpos, mean_chi, color='#a78bfa')
ax[2].set_xticks(xpos)
ax[2].set_xticklabels(fluids_order, rotation=45)
ax[2].set_ylabel("max |chi|")
ax[2].set_title("Mean chi excitation")

plt.tight_layout()
plt.savefig("stur_sonolum.png", dpi=150)
plt.show()

        "mean_Rmin": dict(zip(fluids_order, [float(r) for r in mean_Rmin])),
        "mean_chi": dict(zip(fluids_order, [float(c) for c in mean_chi])),
        "chi_collapse_correlation": float(chi_corr)
    },
    "falsification": {

        ],

    },

}

with open(OUT_JSON, "w") as f:
    json.dump(report, f, indent=2)

print(json.dumps(report, indent=2))
print(f"\nFALSIFIED = {falsified}")
print("STUR Sonoluminescence Lab v9.2 Complete.")
