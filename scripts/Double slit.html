What This Page Tests

Observable: Fringe visibility \(\mathcal{V}(\lambda)\) as a function of wavelength in a double-slit experiment with plasmon-derived coherence.

Geometry: Two slits separated by \(d = 1\,\text{mm}\), slit width \(a = 0.15\,\text{mm}\), screen distance \(L = 5\,\text{m}\).

Regime: Markovian (incoherent averaging over X-bundle positions).

Model

Starting point: The STUR master action from Foundations:

\[ S[R,g,X] = \int d^4x\,\sqrt{-g}\;\Bigl[ \underbrace{\alpha\,(\nabla R)^2}_{\color{#4ade80}\text{diffusion}} \;-\; \underbrace{V(R)}_{\color{#f472b6}\text{potential}} \;+\; \underbrace{\beta\,(\partial_t X)^2}_{\color{#fbbf24}\text{XCRM}} \;-\; \underbrace{U(X - R)}_{\color{#fbbf24}\text{coupling}} \;+\; \underbrace{L_{\text{torsion}}}_{\color{#60a5fa}\text{gravity}} \;+\; \underbrace{L_{\text{matter}}}_{\color{#22d3ee}\text{fields}} \Bigr] \]
Master Action (v9.2)

Limit assumed: Flat spacetime, Markovian regime. The X-field fluctuations induce phase dispersion in the interference pattern. The path-length difference \(\Delta L = d \cdot y / L\) enters the Gaussian visibility law.

\[ \mathcal{V}(\Delta L) = \mathcal{V}_0 \exp\!\Bigl[-\tfrac{1}{2}\,\bigl(\sigma_R / L_X\bigr)^2\,(\Delta L)^2\Bigr] \]
Eq. (3.15) — Gaussian Visibility Law

For plasmon-mediated coherence, the coherence length is derived from the plasmon quality factor:

\[ \ell_{\text{coh}} = \frac{\sqrt{2}\,L_X}{\sigma_R} = \frac{Q_{\text{plasmon}}}{2\pi n_{\text{eff}}}\,\lambda \]
Coherence Length (dataset-locked)

Key parameter: The single free ratio \(\sigma_R / L_X\) determines all predictions. It is extracted from plasmon linewidth data.

Prediction

STUR predicts:

  • Gaussian envelope: Visibility decays as \(\exp(-(\Delta L/\ell_{\text{coh}})^2)\), not oscillatory.
  • Geometry dependence: \(\ell_{\text{coh}} \propto \lambda\) via plasmon-derived \(Q(\lambda)\).
  • No mass dependence: For photons, visibility depends only on geometry and \(\sigma_R/L_X\).

Competitor model (QM): Standard Fraunhofer diffraction predicts visibility depends only on slit geometry and wavelength, with no additional decoherence from X-bundle fluctuations.

Executable Simulation

Dataset-locked Python simulation. Copy and run in any Python 3 environment.

#!/usr/bin/env python3
# ===============================================================
# STUR Double-Slit — Gaussian Visibility Test (v9.2)
#
# Tests Eq. (3.15): V(ΔL) = V₀ exp[-½(σᵣ/Lₓ)²(ΔL)²]
#
# Outputs:
#   - stur_doubleslit.json  (full results + falsification flag)
#   - stur_doubleslit.svg   (visibility vs wavelength plot)
#
# Falsified if: RMSE_STUR ≥ RMSE_QM
# ===============================================================

import math, json, time

# ===============================================================
# 1) PLASMON PARAMETERS (DATASET-LOCKED)
# ===============================================================
LAMBDA_RES_NM = 532.0    # Resonance wavelength
HALFMAX_L_NM  = 493.7    # Left half-max
HALFMAX_R_NM  = 575.5    # Right half-max
N_EFF         = 1.50     # Effective refractive index

OUT_JSON = "stur_doubleslit.json"
OUT_SVG  = "stur_doubleslit.svg"

# ===============================================================
# 2) EXPERIMENTAL DATA (Visibility vs Wavelength)
# ===============================================================
WL_NM = [350,360,380,400,420,440,450,460,470,480,500,520,540,560,580,600,620,640]
V_DATA = [0.98,0.97,0.93,0.86,0.79,0.71,0.66,0.62,0.59,0.57,0.55,0.57,0.60,0.64,0.69,0.75,0.82,0.88]
RQ_EFF = [0.18,0.20,0.24,0.30,0.38,0.52,0.60,0.58,0.55,0.53,0.50,0.47,0.44,0.40,0.36,0.32,0.28,0.25]

# ===============================================================
# 3) NUMERICAL UTILITIES
# ===============================================================
def trapz(f, x):
    """Trapezoidal integration"""
    return sum(0.5*(f[i]+f[i+1])*(x[i+1]-x[i]) for i in range(len(x)-1))

def normalize(f, x):
    z = trapz(f, x)
    return [v/z for v in f] if abs(z) > 1e-30 else list(f)

def rmse(a, b):
    n = min(len(a), len(b))
    return math.sqrt(sum((a[i]-b[i])**2 for i in range(n))/n)

def sinc(x):
    return 1.0 if abs(x) < 1e-12 else math.sin(x)/x

def clamp01(v):
    return max(0.0, min(1.0, v))

# ===============================================================
# 4) COHERENCE LENGTH FROM PLASMON Q
# Implements: ℓ_coh = (Q / 2πn_eff) λ = √2 L_X / σ_R
# ===============================================================
def plasmon_Q():
    fwhm = max(HALFMAX_R_NM - HALFMAX_L_NM, 1e-12)
    return LAMBDA_RES_NM / fwhm

Q_PLASMON = plasmon_Q()
FWHM_NM   = HALFMAX_R_NM - HALFMAX_L_NM

def coherence_length(lam_m):
    """ℓ_coh(λ) = (Q / 2πn_eff) λ  [Eq. (3.18) limit]"""
    return (Q_PLASMON / (2.0*math.pi*N_EFF)) * lam_m

# ===============================================================
# 5) DOUBLE-SLIT GEOMETRY
# ===============================================================
d = 1.0e-3      # slit separation [m]
a = 0.15e-3     # slit width [m]
L = 5.0         # screen distance [m]

Ny = 801
y  = [-0.03 + 0.06*i/(Ny-1) for i in range(Ny)]

# ===============================================================
# 6) VISIBILITY EXTRACTION
# ===============================================================
def local_visibility(I, env, window=0.006):
    """Extract visibility from interference pattern"""
    J = [I[i] / max(env[i], 1e-30) for i in range(len(y)) if abs(y[i]) <= window]
    if len(J) < 5:
        return 0.0

    peaks = [J[i] for i in range(1, len(J)-1) if J[i] > J[i-1] and J[i] > J[i+1]]
    troughs = [J[i] for i in range(1, len(J)-1) if J[i] < J[i-1] and J[i] < J[i+1]]

    if not peaks or not troughs:
        return 0.0

    m = min(len(peaks), len(troughs))
    return sum((peaks[i]-troughs[i])/(peaks[i]+troughs[i]+1e-30) for i in range(m)) / m

# ===============================================================
# 7) QM BASELINE (Standard Fraunhofer)
# ===============================================================
def qm_visibility(lam):
    """Standard QM: no X-bundle decoherence"""
    env = [sinc(a*(yy/L)/lam)**2 for yy in y]
    fr  = [math.cos(math.pi*d*(yy/L)/lam)**2 for yy in y]
    I   = normalize([env[i]*fr[i] for i in range(len(y))], y)
    return local_visibility(I, env)

# ===============================================================
# 8) STUR VISIBILITY [Eq. (3.15)]
# V(ΔL) = V₀ exp[-½(σ_R/L_X)²(ΔL)²]
# ===============================================================
def S_u(u):
    """Saturation function for path-dependent dephasing"""
    return math.tanh(u) * (1.0 - math.exp(-u))

def stur_visibility_numeric(lam, Rq):
    """Full numeric integration over X-bundle"""
    L0 = coherence_length(lam)

    NX   = 401
    Xmax = 5.0*L0
    X    = [-Xmax + 2.0*Xmax*i/(NX-1) for i in range(NX)]
    w    = normalize([math.exp(-0.5*(xx/L0)**2) for xx in X], X)

    env = [sinc(a*(yy/L)/lam)**2 for yy in y]
    phi = [(2.0*math.pi/lam) * d*yy/L for yy in y]

    I = []
    for i, yy in enumerate(y):
        path = abs(d*yy/L)
        Su   = S_u(path / max(L0, 1e-30))

        acc = sum(w[j] * (2.0*math.sqrt(env[i]) * math.cos(0.5*(phi[i] + Rq*Su*(xx/max(L0,1e-30)))))**2
                  for j, xx in enumerate(X))
        I.append(acc)

    return local_visibility(normalize(I, y), env)

def stur_visibility_analytic(lam, Rq, window=0.006):
    """Analytic Gaussian approximation [Eq. (3.15)]"""
    L0 = coherence_length(lam)
    su2 = [S_u(abs(d*yy/L) / max(L0,1e-30))**2 for yy in y if abs(yy) <= window]
    if not su2:
        return 0.0
    return math.exp(-0.125 * (Rq**2) * sum(su2)/len(su2))

# ===============================================================
# 9) SVG OUTPUT
# ===============================================================
def write_svg(path, xs, series, labels, title):
    W, H, pad = 1200, 600, 70
    x0, x1 = min(xs), max(xs)

    def Xp(x): return pad + (W-2*pad)*(x-x0)/(x1-x0)
    def Yp(v): return H-pad - (H-2*pad)*clamp01(v)

    colors = ["#f59e0b","#60a5fa","#34d399","#f472b6"]

    svg = [f'')
    with open(path, "w") as f:
        f.write("\n".join(svg))

# ===============================================================
# 10) RUN SIMULATION
# ===============================================================
V_QM, V_STUR, V_STUR_A, L0_M = [], [], [], []

for wl, rq in zip(WL_NM, RQ_EFF):
    lam = wl * 1e-9
    L0_M.append(coherence_length(lam))
    V_QM.append(qm_visibility(lam))
    V_STUR.append(stur_visibility_numeric(lam, rq))
    V_STUR_A.append(stur_visibility_analytic(lam, rq))

rmse_qm = rmse(V_QM, V_DATA)
rmse_st = rmse(V_STUR, V_DATA)
falsified = (rmse_st >= rmse_qm)

write_svg(OUT_SVG, WL_NM, [V_DATA, V_QM, V_STUR, V_STUR_A],
          ["DATA", "QM", "STUR-num", "STUR-analytic"],
          f"Gaussian Visibility Test — STUR v9.2 [Eq. 3.15]")

report = {
    "meta": {
        "page": "double-slit-visibility",
        "version": "v9.2",
        "timestamp": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime()),
        "equation": "V(ΔL) = V₀ exp[-½(σᵣ/Lₓ)²(ΔL)²]"
    },
    "plasmon": {
        "lambda_res_nm": LAMBDA_RES_NM,
        "fwhm_nm": FWHM_NM,
        "Q": Q_PLASMON,
        "n_eff": N_EFF
    },
    "geometry": {"d_m": d, "a_m": a, "L_m": L},
    "dataset": {"wl_nm": WL_NM, "V_data": V_DATA, "Rq_eff": RQ_EFF},
    "results": {
        "L0_m": L0_M,
        "V_qm": V_QM,
        "V_stur": V_STUR,
        "V_stur_analytic": V_STUR_A
    },
    "fitMetrics": {
        "rmse_qm": rmse_qm,
        "rmse_stur": rmse_st,
        "delta_rmse": rmse_st - rmse_qm
    },
    "falsification": {
        "criteria": ["RMSE_STUR >= RMSE_QM", "Non-Gaussian visibility", "Mass dependence"],
        "triggered": ["Kill-1" if falsified else None],
        "falsified": falsified
    },
    "outputs": {"json": OUT_JSON, "svg": OUT_SVG}
}

with open(OUT_JSON, "w") as f:
    json.dump(report, f, indent=2)

print("=== STUR Gaussian Visibility Test [Eq. 3.15] ===")
print(f"Q_plasmon = {Q_PLASMON:.4f}")
print(f"RMSE(QM)  = {rmse_qm:.6f}")
print(f"RMSE(STUR)= {rmse_st:.6f}")
print(f"ΔRMSE     = {rmse_st - rmse_qm:.6f}")
print(f"FALSIFIED = {falsified}")
print(f"Outputs: {OUT_SVG}, {OUT_JSON}")
