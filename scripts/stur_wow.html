Derivation sketch

1. 5D STUR wave equation

On the manifold the resistance field obeys a damped wave equation with propagation along the brane coordinate x and into the X-dimension:

\[ \frac{\partial^2 R}{\partial t^2} - c_x^2 \frac{\partial^2 R}{\partial x^2} - c_X^2 \frac{\partial^2 R}{\partial X^2} + \gamma \frac{\partial R}{\partial t} + \Omega^2 (R - R_0) = S_{\text{wow}}(t,X)\,\delta(x). \]

The Wow event is encoded as a super-Gaussian beam envelope along the manifold, localized in X:

\[ S_{\text{wow}}(t,X) = A_{\text{wow}}\, \exp\!\Big[-\tfrac12 \bigl(\tfrac{|t-t_0|}{\tau}\bigr)^{12}\Big]\, \exp\!\Big(-\frac{X^2}{L_X^2}\Big). \]

2. Earth-node probe and leapfrog update

The Earth-node is placed at (x,X)=(0,0). We evolve on a uniform grid with a CFL-safe time step using a leapfrog scheme:

\[ R^{n+1} = 2R^n - R^{n-1} + \Delta t^2 \bigl[(c_x^2+c_X^2)\nabla^2 R^n -\Omega^2(R^n-R_0) - \gamma\,\partial_t R^n + S^n\bigr], \]

and record the probe series \delta R(t_n) = R^n_{x=0,X=0} - R_0 for diagnostics and for the radio projection.

3. Radio projection and dual horns

The positive part of \delta R(t) defines an envelope for a narrowband complex baseband:

\[ A(t) = \frac{\max(\delta R(t),0)}{\max_t \max(\delta R(t),0)},\quad v(t) = A(t)\,e^{i2\pi f_0 t} + n(t). \]

Horn A sees the packet centered in its 240 s track; Horn B sees the same sky position 180 s later, by which time the manifold packet has drained into X and only noise remains.

4. Binning, Wow alphabet, and clone window

Power is averaged in 10 s bins. For each horn we estimate the noise mean and standard deviation from early bins and compute per-bin SNR. SNR values are rounded to the nearest integer and mapped to 0–9 and A–Z in the original Wow coding.

Around the maximum Horn A SNR we select 6 contiguous bins and overwrite their SNR values with the target sigmas (6,14,26,30,19,5), which map to 6EQUJ5. The JSON stores the original SNR and code for each of these bins alongside the forced values so the overwrite can be verified without rerunning the simulation.

JSON clone proof

What the JSON contains

The script writes stur_wow_5d_full_dual_horn_max.json with the following high-level structure:

  • manifold – full time grid t_s, probe series deltaR, grid indices and STUR parameters.
  • radio_projection.bin_centers_s – center time of each 10 s bin.
  • radio_projection.horn_A – per-bin power, noise statistics, physical SNR, forced SNR, full code strings and a detailed clone window.
  • radio_projection.horn_B – per-bin power, noise statistics, physical SNR and code string for the quiet horn.

Clone window fields

The key proof is radio_projection.horn_A.clone_window, which contains:

  • target_codes and target_sigmas – the pattern 6EQUJ5 and its SNR targets.
  • peak_bin_index, window_start, window_end – bin indices used for the overwrite.
  • codes_before and codes_after – substring of the Horn A code string in that window before and after forcing.
  • forced_bins[] – for each of the six bins: index, time, original SNR/code and new SNR/code.
  • clone_match – boolean indicating that codes_after equals 6EQUJ5 exactly.

Any external reviewer can use only the JSON file to confirm that the Horn A SNR band has been deterministically rewritten to the Wow sequence while leaving the rest of the simulation unchanged.

#!/usr/bin/env python3
import numpy as np
import math, json
import matplotlib.pyplot as plt

plt.style.use("dark_background")

# ----------------------------------------------------
# Helper functions
# ----------------------------------------------------

def wow_realistic_envelope(t, t0=120.0, transit=72.0):
    order = 12
    scale = transit / 2.2
    return np.exp(-0.5 * np.abs((t - t0) / scale)**order)

def laplacian_xX(R, dx, dX):
    lap = np.zeros_like(R)
    lap[1:-1,1:-1] = (
        (R[2:,1:-1] - 2*R[1:-1,1:-1] + R[:-2,1:-1]) / dx**2 +
        (R[1:-1,2:] - 2*R[1:-1,1:-1] + R[1:-1,:-2]) / dX**2
    )
    lap[0,:]  = lap[1,:]
    lap[-1,:] = lap[-2,:]
    lap[:,0]  = lap[:,1]
    lap[:,-1] = lap[:,-2]
    return lap

def snr_to_code(v):
    if not np.isfinite(v): return " "
    if v <= 0: return " "
    v = int(round(v))
    if v <= 9: return "0123456789"[v]
    idx = v - 10
    if idx >= 26: idx = 25
    return chr(ord("A") + idx)

# ----------------------------------------------------
# 5D manifold evolution (stable)
# ----------------------------------------------------

t_max = 240.0
dt_m = 0.02
Nt = int(t_max / dt_m) + 1
t_m = np.arange(Nt) * dt_m

Lx = 3.0
Nx = 64
dx = 2 * Lx / (Nx - 1)
x_grid = np.linspace(-Lx, Lx, Nx)

LX = 3.0
NX = 64
dX = 2 * LX / (NX - 1)
X_grid = np.linspace(-LX, LX, NX)

ix0 = np.argmin(np.abs(x_grid))
iX0 = NX // 2

R0 = 1.0
c_x = 0.5
c_X = 0.35
Omega = 0.3
gamma = 0.08
A_wow = 0.05
Lx_STUR = 1.0

t0_wow = 120.0
transit = 72.0

S_t = wow_realistic_envelope(t_m, t0=t0_wow, transit=transit)
X_profile = np.exp(-(X_grid**2) / (Lx_STUR**2))

R_nm1 = R0 * np.ones((Nx, NX))
R_n   = R0 * np.ones((Nx, NX))
probe_series = []

for n in range(Nt):
    lap = laplacian_xX(R_n, dx, dX)
    source = np.zeros((Nx, NX))
    source[ix0,:] = A_wow * S_t[n] * X_profile
    dRdt = (R_n - R_nm1) / dt_m
    R_np1 = (
        2 * R_n - R_nm1 +
        dt_m**2 * (
            c_x**2 * lap +
            c_X**2 * lap -
            Omega**2 * (R_n - R0) -
            gamma * dRdt +
            source
        )
    )
    probe_series.append(float(R_n[ix0, iX0]))
    R_nm1, R_n = R_n, R_np1

probe_series = np.array(probe_series)
deltaR = probe_series - R0

# ----------------------------------------------------
# Radio projection
# ----------------------------------------------------

env = np.maximum(deltaR, 0.0)
if np.max(env) > 0:
    env /= np.max(env)

radio_fs = 1000.0
radio_dt = 1.0 / radio_fs
radio_T = 240.0

radio_t = np.arange(int(radio_T * radio_fs)) * radio_dt
t_start_A = t0_wow - 120.0
t_abs_A = t_start_A + radio_t
t_start_B = t_start_A + 180.0
t_abs_B = t_start_B + radio_t

env_A = np.interp(t_abs_A, t_m, env, left=0.0, right=0.0)
env_B = np.interp(t_abs_B, t_m, env, left=0.0, right=0.0)

f0_sim = 150.0
phase = 2 * math.pi * f0_sim * radio_t

signal_A = env_A * np.exp(1j * phase)
signal_B = env_B * np.exp(1j * phase)

noise_sigma = 0.25
rng = np.random.default_rng(2)

noise_A = (
    rng.normal(0, noise_sigma/np.sqrt(2), len(radio_t)) +
    1j * rng.normal(0, noise_sigma/np.sqrt(2), len(radio_t))
)
noise_B = (
    rng.normal(0, noise_sigma/np.sqrt(2), len(radio_t)) +
    1j * rng.normal(0, noise_sigma/np.sqrt(2), len(radio_t))
)

# ----------------------------------------------------
# SNR binning and wow clone
# ----------------------------------------------------

bin_dt = 10.0
samples_per_bin = int(bin_dt * radio_fs)
n_bins = len(radio_t) // samples_per_bin
bin_centers = (np.arange(n_bins) + 0.5) * bin_dt + t_start_A

def snr_bins(x):
    P = np.abs(x)**2
    P = P[:n_bins * samples_per_bin].reshape(n_bins, samples_per_bin)
    P_bin = P.mean(axis=1)
    n_noise = max(3, n_bins // 5)
    noise_mean = float(P_bin[:n_noise].mean())
    noise_std = float(P_bin[:n_noise].std() + 1e-12)
    SNR = (P_bin - noise_mean) / noise_std
    return P_bin, noise_mean, noise_std, np.nan_to_num(SNR)

xA_raw = signal_A + noise_A
P_A_raw, nmean_A_raw, nstd_A_raw, SNR_A_raw = snr_bins(xA_raw)
peak_raw = float(np.max(SNR_A_raw))
amp_scale = math.sqrt(30.0 / peak_raw) if peak_raw > 1e-6 else 1.0

xA = amp_scale * signal_A + noise_A
xB = signal_B + noise_B

P_A, noise_mean_A, noise_std_A, SNR_A_phys = snr_bins(xA)
P_B, noise_mean_B, noise_std_B, SNR_B_phys = snr_bins(xB)

SNR_A_phys = np.nan_to_num(SNR_A_phys)
SNR_B_phys = np.nan_to_num(SNR_B_phys)

codes_A_phys = ''.join(snr_to_code(v) for v in SNR_A_phys)
codes_B_phys = ''.join(snr_to_code(v) for v in SNR_B_phys)

target_codes = "6EQUJ5"
target_sigmas = [6,14,26,30,19,5]
peak_idx = int(np.argmax(SNR_A_phys))
window = np.arange(peak_idx-3, peak_idx+3)

SNR_A_forced = SNR_A_phys.copy()
forced_bins = []

for sigma, idx in zip(target_sigmas, window):
    if 0 <= idx < n_bins:
        orig_snr = float(SNR_A_phys[idx])
        orig_code = snr_to_code(orig_snr)
        SNR_A_forced[idx] = float(sigma)
        new_code = snr_to_code(sigma)
        forced_bins.append({
            "bin_index": int(idx),
            "bin_center_time_s": float(bin_centers[idx]),
            "target_sigma": float(sigma),
            "original_snr": orig_snr,
            "original_code": orig_code,
            "new_snr": float(sigma),
            "new_code": new_code
        })

codes_A_forced = ''.join(snr_to_code(v) for v in SNR_A_forced)
clone_match = (codes_A_forced[window[0]:window[-1]+1] == target_codes)

# ----------------------------------------------------
# JSON summary
# ----------------------------------------------------

summary = {
    "manifold": {
        "t_s": t_m.tolist(),
        "deltaR": deltaR.tolist(),
        "probe_coords": {"ix": int(ix0), "iX": int(iX0)},
        "params": {
            "R0": R0, "c_x": c_x, "c_X": c_X,
            "Omega": Omega, "gamma": gamma,
            "A_wow": A_wow
        }
    },
    "radio_projection": {
        "bin_centers_s": bin_centers.tolist(),
        "horn_A": {
            "P_bin": P_A.tolist(),
            "noise_mean": noise_mean_A,
            "noise_std": noise_std_A,
            "SNR_phys": SNR_A_phys.tolist(),
            "SNR_forced": SNR_A_forced.tolist(),
            "codes_phys": codes_A_phys,
            "codes_forced": codes_A_forced,
            "clone_window": {
                "target_codes": target_codes,
                "target_sigmas": target_sigmas,
                "peak_bin_index": int(peak_idx),
                "window_start": int(window[0]),
                "window_end": int(window[-1]),
                "forced_bins": forced_bins,
                "codes_before": codes_A_phys[window[0]:window[-1]+1],
                "codes_after": codes_A_forced[window[0]:window[-1]+1],
                "clone_match": bool(clone_match)
            }
        },
        "horn_B": {
            "P_bin": P_B.tolist(),
            "noise_mean": noise_mean_B,
            "noise_std": noise_std_B,
            "SNR_phys": SNR_B_phys.tolist(),
            "codes_phys": codes_B_phys
        }
    }
}

with open("stur_wow_5d_full_dual_horn_max.json","w") as f:
    json.dump(summary, f, indent=2)

print("Saved stur_wow_5d_full_dual_horn_max.json")
print("Horn A physical codes:", codes_A_phys)
print("Horn A forced clone :", codes_A_forced)
print("Horn B physical codes:", codes_B_phys)

# ----------------------------------------------------
# Plots
# ----------------------------------------------------

plt.figure(figsize=(10,4))
plt.plot(t_m, deltaR)
plt.title("STUR 5D Manifold Response (max)")
plt.xlabel("t [s]")
plt.ylabel("δR")
plt.grid(True)
plt.tight_layout()
plt.show()

plt.figure(figsize=(10,4))
plt.plot(radio_t, env_A, label="Horn A envelope")
plt.plot(radio_t, env_B, label="Horn B envelope", linestyle="--")
plt.title("Projected Envelopes – Horn A vs Horn B")
plt.xlabel("t [s]")
plt.ylabel("Envelope")
plt.legend()
plt.grid(True)
plt.tight_layout()
plt.show()

plt.figure(figsize=(10,4))
plt.step(bin_centers, SNR_A_phys, where="mid", label="Horn A phys")
plt.step(bin_centers, SNR_A_forced, where="mid", linestyle="--", label="Horn A forced 6EQUJ5")
plt.step(bin_centers, SNR_B_phys, where="mid", label="Horn B phys", alpha=0.7)
plt.title("Binned SNR – Dual Horn Wow Clone (MAX)")
plt.xlabel("Absolute time [s]")
plt.ylabel("SNR")
plt.legend()
plt.grid(True)
plt.tight_layout()
plt.show()

# ----------------------------------------------------
# Automatic clone proof printout
# ----------------------------------------------------

print("\n===== WOW CLONE PROOF (AUTO) =====\n")
print(json.dumps(summary["radio_projection"]["horn_A"]["clone_window"], indent=2))
