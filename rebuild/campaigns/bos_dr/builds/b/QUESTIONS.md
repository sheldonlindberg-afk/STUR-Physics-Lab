# SPEC ambiguities and resolutions (bos_dr-b)
1. delta_vb "with the on-shell W-l-nu coupling counterterm not included": the bare vertex+box+wave-function sum delta_V has a UV pole 4 g^2/(16 pi^2) (= C_A g^2 per vertex), so it is not a scheme-free number; the SPEC also says delta_vb depends only on s^2 and takes no mu. Resolution: exported delta_vb = delta_V + 2 Sigma_AZ(0)/(s c M_Z^2) (the mixing piece of the charge relation moved into the vertex group, Denner-type grouping with -2(c/s) Sigma_AZ(0) in the Sigma part) = (alpha/(4 pi s^2))(6 + (7-4 s^2)/(2 s^2) ln c^2); numerically equal to delta_V in MS-bar at mu = M_W. Delta r_bos itself is independent of this choice.
2. Fermi QED subtraction: realized as vanishing of the Fermi-theory correction at zero momentum in charge-retention order (Ward identity); photon mass lambda cancels between box and lepton wave function.
3. Sign/convention of Sigma_AZ: used as in SPEC (+Sigma_AZ in the inverse propagator matrix); the derived charge relation has -2 (s/c) Sigma_AZ(0)/M_Z^2 in e^2/e0^2, confirmed by exact mu cancellation.
4. Sigma_AA'(0): numerical extrapolation (module returns Sigma_AA only).
6. Large M_H: the documented float exports sigma_W, sigma_ZZ lose the answer to cancellation (M_H^2-sized pieces that cancel in Delta r) for M_H above about 1e9 GeV (error ~1e-4 relative at 1e9, wrong at 1e14). The first version used bos_se private helpers to get mpf values; that is removed. Now the exports are called only at M_H0 = M_W and the Higgs-diagram M_H dependence is derived (DERIVATION section 9) and added in local-precision mpmath; no global mp precision and no bos_se private state are used.
