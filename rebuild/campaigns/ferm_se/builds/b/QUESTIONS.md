# SPEC ambiguities and resolutions
1. Sign of the A-Z mixing: fixed by SPEC D_mu and Z = cW3 - sB, A = sW3 + cB: Z coupling (g/c)(T3 - s^2 Q), photon eQ; Sigma^AZ = + e Q (gL+gR)-weighted bubble.
2. gamma5 / O(eps) treatment: transverse g^{mu nu} part has no gamma5 contribution; (2/d - 1) l^2 -> -Delta I0 exactly, so no extra rational term arises.
3. Above threshold: real part (ln|Delta|). 4. Neutrino (m=0,Q=0): right-handed Z coupling set to 0 (also 0 by Q=0, m=0 mass term).
5. W: loop with doublet weight w multiplies the single bubble (g/sqrt2 V-A).
