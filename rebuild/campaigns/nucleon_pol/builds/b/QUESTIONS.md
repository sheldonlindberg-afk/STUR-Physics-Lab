# SPEC ambiguities and resolutions
1. SPEC lists "alpha_E, beta_M read off from O(omega^2) forward Compton amplitude" but forward gives only alpha+beta. Resolved via H_eff definition: static energy shifts in E and B (separately).
2. Heaviside-Lorentz: E^2 term -2pi alpha_E E^2 means d = 4 pi alpha_E E; used verbatim, e^2 = 4 pi alpha.
3. "f_pi ~ 92 MeV" normalization: used f in U=exp(i tau.pi/f), gA/(2f) tau.sigma.grad pi coupling.
4. Weights: proton used; isospin symmetry (neutron gives same by charge-conjugated pi- <-> pi+ weights) asserted, not computed separately.
5. Sign/Born: Born subtraction = dropping nucleon-reducible graphs (see DERIVATION section 2).
6. Not computed: the explicit covariant HB Compton diagrams; replaced by static functional.
